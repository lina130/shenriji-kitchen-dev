# 深城日常

> 没有强制主线，没有数值面板，你的人生你说了算。

本仓库是《深城日常》的 Godot 工程。当前开发目标严格遵守总案顺序：先完成阶段 0 技术底座，再完成 MVP 0.1 的“起床 → 出门 → 打工 → 赚钱 → 消费/交租 → 睡觉”单日闭环。

## 当前能力

- Godot 4.2+ 工程骨架与模块化 Autoload
- 全局时间、存档、背包、随机数、地点路由、弱提示框架
- 像素风占位场景，不依赖外部美术即可运行
- 出租屋、街道、工厂、便利店四个占位区域
- 移动、右键交互、打工、购买、吃饭、睡觉、房租、月结闭环
- 全感知状态：无数值属性条，精力通过画面、步速和事件反馈

## 运行

双击或在 PowerShell 执行：

```powershell
.\run_editor.ps1   # 打开 Godot 编辑器
.\run_game.ps1     # 直接试玩
.\check_project.ps1 # 无窗口加载测试
```

如果系统已安装 Godot，可直接用 Godot 打开本目录中的 `project.godot`。项目也会优先使用 `.tools/godot` 内的便携版。

## 操作

- `WASD` / 方向键：移动
- 鼠标右键：与身边物件互动
- `E`：便捷互动键
- `I`：背包
- `F5`：保存
- `F9`：读取
- `Esc`：关闭界面 / 退出鼠标模式

## 目录

- `autoload/`：全局系统
- `scripts/gameplay/`：玩家、世界、交互物
- `scripts/ui/`：弱 UI 与极简界面
- `scripts/data/`：数据定义
- `scenes/`：入口场景
- `assets/`：美术与音频资源
- `data/`：CSV / JSON 配置
- `docs/`：开发总案、规范与阶段验收
