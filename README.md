# 深城日常

> 没有强制主线，没有数值面板，你的人生你说了算。

当前版本：`0.1.0 垂直切片发布候选版`。这是首个可独立运行、可打包分发的 Windows 版本，重点验证“生存、工作、消费、摸金、关系、成长、交租”能否形成耐玩的日常闭环。

## 发行包

Windows 独立版：

`release\深城日常_0.1.0_win64.zip`

解压后双击 `深城日常.exe`，无需安装 Godot。

## 本版内容

- 出租屋、街道、工厂、便利店、废品回收站、旧货市场、社区公园。
- 工厂班次、便利店兼职、固定物价消费和 30 日房租结算。
- 每日城市摸金、四级稀有度、旧物册、出售和 NPC 礼物。
- 晴、阴、雨、回南天、酷暑五种天气与新系统联动。
- 四位 NPC、生活化对话、模糊关系阶段和隐藏喜好。
- 学习、锻炼、职业熟练度等隐藏成长，全部通过事件和体感反馈。
- 主菜单、设置、继续游戏、F5/F9 扩展存档。
- 原创程序化氛围音乐、环境音与反馈音。
- 无数值属性条、无任务列表、无红点压迫。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标右键 | 核心互动 |
| E | 便捷互动 |
| I | 背包 |
| C | 旧物册 |
| M | 地图 |
| B | 生活账本 |
| F5 / F9 | 保存 / 读取 |
| Esc | 暂停、关闭界面、主菜单 |

## 开发

```powershell
.\run_editor.ps1    # 打开 Godot 编辑器
.\run_game.ps1      # 直接试玩
.\run_tests.ps1     # 自动验收
.\run_stress_test.ps1 # 100 次随机 30 日经济压力测试
.\build_release.ps1 # 测试、导出、计算哈希并压缩发布包
```

正式数值统一在 `data/*.csv`。构建脚本会同步 `.csv.txt` 纯文本副本，确保导出后的 PCK 仍能读取固定物价。

## 目录

- `autoload/`：时间、天气、摸金、关系、成长、存档、设置、音频。
- `scripts/gameplay/`：玩家、NPC、世界、交互物、天气表现。
- `scripts/ui/`：主菜单、HUD 与生活界面。
- `data/`：固定物价、物品、天气、NPC 配置。
- `assets/`：原创程序化音频与后续正式美术资源。
- `docs/`：开发总案、架构、发行说明、已知问题和验收清单。
- `release/`：可直接分发的 Windows 包与 SHA-256。

## 版本边界

`0.1.0` 是首个公开试玩垂直切片，不包含完整商业内容量、正式像素美术、完整人生路线、复杂经营、Steam 成就和联机。详细说明见 `docs\KNOWN_ISSUES.md`。
