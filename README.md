# 深城日常

> 没有强制主线，没有复杂血条，你的人生和生意都由自己安排。

当前版本：`0.3.1 深夜食堂经营版`。赚钱不再是单一打工，而是围绕脑力、劳力、商品库存和实时出餐形成可持续放大的经营循环。

## 发行包

`release\深城日常_0.3.1_win64.zip`

解压后双击 `深城日常.exe`，无需安装 Godot。

## 核心赚钱循环

`批发进货 → 管理脑力/劳力/食材 → 接订单 → 备料 → 下锅 → 装盘 → 上菜 → 收款 → 扩店`

- 每日食材价格随机变化，可以买低卖高，也可能亏损。
- 每道菜真实消耗食材、劳力和脑力，缺库存就不能开工。
- 订单有耐心，漏单会失去连击和口碑。
- 菜品在下锅、装盘、上菜阶段都需要玩家操作。
- 档口规模越大，工位越多，菜单越丰富，赚钱速度越快。
- 城中村有实体银行与彩票站，银行支持存取款和每日利息。
- 彩票有高额奖项，但长期期望为亏损。
- 商铺达到规模后可转让，获得大额资金和稀有纪念物。
- 旧址、旧货行情、寄卖和熟客口碑继续构成长期探索循环。\n- 熟人会带来进货折扣，老朋友会提高客人耐心并赠送稀有旧物。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标右键 | 核心互动 |
| I | 背包 |
| C | 旧物册 |
| M | 地图 |
| B | 银行与彩票 |
| K | 夜市档口经营 |
| F5 / F9 | 保存 / 读取 |
| Esc | 暂停或关闭界面 |

## 开发验证

```powershell
.\run_tests.ps1
.\run_stress_test.ps1
.\run_full_simulation.ps1
.\run_playtest.ps1
.\build_release.ps1
```

`run_full_simulation.ps1` 会模拟数十到数百个游戏日，直到 24 件旧物全部收集、银行产生利息、多轮经营完成，并让总资产达到 5 万以上。`build_release.ps1` 将完整模拟与真实窗口 44 步操作测试作为强制发布门禁。

正式数值统一在 `data/*.csv`。构建脚本同步 `.csv.txt` 供导出 PCK 读取。
