# 深城日常

## 一键试玩：深圳湾人才公园湖畔餐馆

在仓库根目录双击 `试玩人才公园.cmd`，或启动游戏后选择「试玩 · 人才公园湖畔餐馆」。这是与旧版生活存档隔离的微 3D 开发试玩：走到餐馆班铃选择悠闲或忙碌班，依次到备料台、加热台、装盘台和出餐窗完成订单、赚取收入。可花 15 贝买果茶恢复 20 精力、花 60 贝买一次性海风马克杯并在店前看到摆件，或到长椅休息进入次日。

WASD 移动；左键前往/互动；E 与附近物件互动；滚轮缩放；按住右键转动镜头；M 切换人才公园区域总览；F5 手动保存；Esc 返回或退出试玩。进度约每 10 秒及关键操作自动保存到独立的 `user://talent_park_mvp.json`，同时保留一份 `.bak` 供主档损坏时恢复。详见 [人才公园试玩说明](docs/人才公园试玩说明.md)。

当前场景聚焦人才公园、湖畔餐馆与后海商圈地标。地图按官方导览图比例推定，建模以 1 米对应 1 场景单位为目标，尚未经精测，**不能宣称严格 1:1 已完成**。餐馆和地标模型是正式素材候选，仍需精修建筑细节、材质和空间尺度。三职业、全深圳生活版与 11 城大湾区属于后续目标；完成标准见 [开发目标与验收](docs/开发目标与验收.md)，现场操作规则见 [场景交互规范](docs/场景交互规范.md)。

## 核心赚钱循环

`进货/种菜 → 按早中晚菜单接单 → 备料 → 逐工位加工 → 托盘搬运 → 出餐 → 收款 → 扩店/雇人 → 经营与生活系统互相加成`

- 每道菜有自己的工序链，蒸笼、油锅、汤锅、饮品台升级互不通用。
- 半成品可以暂存，但必须手动送到下一类工位。
- 早市、午市、晚市各有菜单、价格、需求和耐心倍率，换市会清场。
- 早餐店包含顾客排队和点餐台出餐，并接同一套多工序生产。
- 员工有工资期望、诉求、士气、疲劳、欠薪、住宿、技能和离职风险。
- 招聘渠道包括劳务市场、老乡介绍、熟人推荐和日结工。
- 角色开局待业，可应聘餐饮、工厂、写字楼、学业、体制、自由职业、物流仓配和手艺技工；晋升只通过负责人暗示，不显示进度条。课程学完后要参加结业考核，证书会成为部分中高级岗位的门槛；长期状态差会收到绩效提醒，严重时被裁员并拿到结算补偿，之后可重新择业。
- 商业区有服装店，购买和穿搭会改变角色外观，并影响经营与社交手感。
- 节日会解锁汤圆、粽子、月饼、饺子等限时商品；13 个节日各有 NPC 事件、限定摊主和纪念旧物。
- 节日活动分成比赛和聚会：比赛按状态与技巧结算名次奖励，聚会恢复情绪、降低压力并增加社交暖意。
- 场景布局门禁会检查交互物重叠、出口碰撞和空气墙；出口必须保留可接近空间，家具上的物件必须至少能鼠标直接点击。
- 18:00–23:00 可进入独立城中村夜市，购买餐馆原料、夜宵和节日限定小食，或帮摊主守一小时。
- 节日限定收集物只在对应日期进入摸金池，场景会随灯笼、雨线、纸风车、月亮、烟火等节日装饰变化。
- 地图拆分为城中村、商业区、工业区和城郊；餐馆、银行、便利店、服装店、工厂、劳务市场、农场等内容不再挤在同一条街。
- 不在店里时，有员工才会产生很慢的被动收入；亲自经营仍是主要收入来源，随机客流和手速决定上限。
- 地摊、小吃饮品店、零售百货店和小型加工厂拥有各自的时间、体力、劳力、脑力和原料表；现场照看会消耗备货并即时结算。
- 农场按星露谷式方向扩展：锄头、洒水壶、堆肥桶、自动喷灌均可升级，雨天自动灌溉，酷暑缺水会拖慢生长，天气还会影响作物收购价。
- 农场圈舍与田地分开，可购买鸡舍、奶牛棚和猪圈；饲料从批发进货，鸡蛋、牛奶、猪肉会按天送入餐馆仓库。
- 新游戏由 NPC 对话展开轻量剧情章节，并在日常生活中触发邻里、加班、行情、天气、孩子和宠物等 34 条偶发事件。
- 梅姨、王师傅、小林、陈伯、黄姐、阿珍、强叔、小雨各自有三段个人支线，会随职业、住房、家庭、兴趣和旅行经历自然推进。
- 经营操作不再依赖 HUD 列表：菜单卡、工位、托盘、设备升级和农场工具都在场景里点击。
- 宠物只会在真正收养后出现在出租屋，未收养时不会提前显示宠物窝。
- 早餐店拆为前厅和后厨，新增河边自然保护区，NPC 拥有性格、用途和周末/节日/时段限时出场。
- 14 位 NPC 拥有早中晚多句对话池，雨雾天气、职业线和关系深浅会改变可选台词，减少重复感。
- NPC 拥有开心、疲惫、担忧等表情头像，提示气泡会根据正面、提示和警告语气自动切换。
- 设置界面可选择 1280×720、1600×900、1920×1080 窗口尺寸，并记住全屏和声音设置。
- 背包与木箱对齐星露谷式固定格位：快捷栏 12 格、背包可升级到 24/36 格、木箱 36 格。
- UI 面板、行动按钮和背包格都走统一主题纹理，后续正式 UI 资源可以直接覆盖。
- 支持拖动整理、右键拆半、Shift+右键整叠转移、Ctrl+右键单件转移，以及数字键快捷栏操作。
- 收购箱放入后由次日收购车结算，不能取回；背包格位和箱子内容都会进入 v12 存档。
- 背包里每件物品都显示用途，种子、宠物用品和装饰物都有实际系统作用。
- 新增像素美术生成管线、四帧行走与工作/吃饭/睡觉/交互/拾取动作、物品图标和 UI 纹理；NPC 会按当天活动切换动作。
- 城市收藏扩展到 100 件旧物，覆盖旧金属、瓷器玻璃、旧书纸品、相机影像和市井杂货五类行情。
- 新增河边钓鱼、住房升级，以及写字楼、学业、体制、自由职业、物流仓配和手艺技工路线。
- 高端住宅区提供云城高层公寓和云端花园住宅，并有楼顶花园、咖啡店与社区画廊。
- 工业区新增物流港仓和手艺工坊，支持装卸、线路查看、维修和手艺练习。
- F1 城市图鉴分为物品、美食、场景、职业、纪念品和旧物六类，会自然记录见过、做过、去过和接触过的内容。
- 图鉴会记录 100 条人生注脚，覆盖职业、班次、住房、养殖、钓鱼、摄影、兴趣、课程、经营和人际关系。
- 成家后可以照看孩子；孩子会随游戏天数成长，并通过喂食、陪伴、教学和出游产生真实关系反馈。
- F6 可创建或加入真实 ENet 合作房间，好友的场景、位置和朝向会同步到当前地图。
- 房主会同步共同资金、库存、店铺、农场、员工、房间和厨房状态；访客可以提交批发、农场、夜市和厨房操作请求，由房主执行并回传最新状态。
- `tools/build_steam_store_pack.py` 会生成 Steam 商店图片、双语介绍、成就清单、云存档清单和上传配置模板。
- 本地模组可从 `user://mods` 以 CSV 数据扩展物品、菜谱、事件、NPC 和其他配置，详见 docs/MODDING.md。
- 农场、宠物、房间、NPC 关系、银行、彩票、批发和旧址探索继续构成长期循环。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标右键 | 核心互动 |
| I | 背包与储物 |
| C | 旧物册 |
| M | 地图 |
| B | 银行与彩票 |
| K | 餐饮流水线 |
| J | 农场 |
| P | 宠物 |
| R | 房间装扮 |
| H | 招工与离职 |
| F2 | 工作与岗位 |
| F3 | 服装与穿着 |

| 右键 / Shift+右键 / Ctrl+右键 | 拆半 / 整叠转移 / 单件转移 |

| F6 | 好友合作房间 |
| Esc | 暂停或关闭界面 |

自动存档每约 15 游戏分钟触发一次，并在换市、开关档、睡觉、交易、雇人离职、种收、宠物行动和买家具等关键节点立即触发。手动档与自动档分开，均采用原子写入并保留 3 份轮转备份。

## 开发验证

```powershell
.\run_tests.ps1
.\run_stress_test.ps1
.\run_full_simulation.ps1
.\run_playtest.ps1
.\build_release.ps1
```

`build_release.ps1` 会强制运行冒烟、完整经营、世界系统、场景、经营、100 月压力和真实窗口测试，再导出 Windows 版并校验桌面最新版哈希。正式数值统一在 `data/*.csv`，构建脚本会同步 `.csv.txt` 供导出 PCK 读取。

美术重构预留：`PresentationManager`、`data/scene_metadata.csv`、`data/visual_bindings.csv`、`data/theme_tokens.csv` 已分离场景、人物、物品、UI 与字体资源键；后续替换正式美术时只改绑定和资源目录，不改业务逻辑。

地图工具链调研：`docs/AI_TEAM_AND_ASSET_TOOLCHAIN.md` 汇总了 MetaGPT、ChatDev、OpenHands、Tiled、LDtk、Aseprite 导入器等方案；当前先用 `data/scene_zones.csv` 做分区与密度校验。

## 仓库结构

```text
深城日常/
├─ project.godot            Godot 4.7 工程配置（主入口）
├─ export_presets.cfg       Windows 导出预设（已排除 tests/docs/tools/output/Godot）
├─ icon.svg                 应用图标
│
├─ autoload/                全局单例：存档、时间、经济、日历、库存、关系、音频…
├─ scenes/                  场景与 UI 预制体
├─ scripts/                 玩法脚本（gameplay / ui）
├─ shaders/                 着色器
├─ assets/                  运行期资源：art（角色 / 模型 / UI / 字体）、audio
├─ data/                    数值表；*.csv 是唯一正式来源，本地会生成 *.csv.txt 供导出读取
├─ addons/                  Godot 插件
│
├─ docs/                    设计文档与实机截图（含 .gdignore，不参与导入与导出）
├─ tests/                   无头测试（smoke / world-systems / economy / stress / playtest…）
├─ tools/                   开发辅助脚本（美术生成、测试选择、发行打包）
│
├─ run_game.ps1             启动游戏
├─ run_editor.ps1           打开编辑器
├─ check_project.ps1        只做一次无头导入自检
├─ run_tests.ps1            冒烟 + 世界系统测试
├─ run_stress_test.ps1      100 月压力测试
├─ run_full_simulation.ps1  完整经营模拟
├─ run_playtest.ps1         真实窗口试玩
├─ build_release.ps1        完整门禁 + Windows 导出
├─ 试玩人才公园.cmd          双击进入人才公园湖畔餐馆试玩
└─ 旧版2D.cmd               双击进入旧版 2D 基线
```

脚本与 `.cmd` 都靠自身位置定位工程根目录，**必须留在仓库根目录**。

以下目录属于本地环境，已写入 `.gitignore`，克隆后按需重建：

| 目录 | 用途 |
| --- | --- |
| `.tools/` | 便携版 Godot、Blender、测试隔离存档等本地工具 |
| `release/` | 导出的 Windows 发行包与 EXE |
| `output/` | 构建 / 测试 / QA 截图与临时 appdata |
| `Godot/` | Godot 编辑器用户数据（含导出模板） |
| `work/` | 一次性脚本草稿 |
| `.godot/` | Godot 导入缓存，首次打开工程会自动重建 |

首次克隆后的最小步骤：放入 Godot 4.7（或把便携版放回 `.tools/godot/`）→ `.\check_project.ps1` 完成一次导入 → `.\run_game.ps1` 启动。
