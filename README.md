# 深城日常

> 没有强制主线，没有数值面板，你的人生你说了算。

当前版本：`0.2.0 旧城经营版`。这一版用完整的旧货经济循环替代装备成长：工作赚钱、逛巷摸金、判断每日行情、立即出售或寄卖、扩大摊位、积累熟客口碑，再解锁更深旧址。

## 发行包

Windows 独立版：

`release\深城日常_0.2.0_win64.zip`

解压后双击 `深城日常.exe`，无需安装 Godot。

## 核心循环

`打工挣钱 → 城市摸金 → 供求行情 → 立即售卖/寄卖 → 摊位扩张 → 熟客信誉 → 深层旧址 → 稀有旧物 → 新的现金周转`

- 每日热门、冷门品类变化，旧物成交价自然浮动。
- 不急用钱时可寄卖，等待行情和熟客带来更高成交概率。
- 摊位升级不是装备，而是经营资产，增加寄卖容量与成交机会。
- 深层旧址由经济进度解锁，不靠数值门槛或任务列表。
- 探索时灯光范围逐渐缩小，靠环境体感判断何时返回。

## 本版内容

- 出租屋、街道、工厂、便利店、废品回收站、旧货市场、社区公园。
- 旧楼地下室、废弃管道层、封存车间、积水隧道四个探索点。
- 22 种城市旧物，普通、少见、稀有、传说四级稀有度。
- 工厂与便利店两条日常收入路线。
- 四位 NPC、生活化对话、喜好礼物和隐藏关系阶段。
- 晴、阴、雨、回南天、酷暑五种天气。
- 学习、锻炼、职业熟练度等隐藏成长。
- 主菜单、设置、F5/F9 扩展存档、原创程序化音频。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标右键 | 核心互动 |
| E | 便捷互动 |
| I | 背包 |
| C | 旧物册 |
| M | 地图 |
| B | 生活账本 |
| F5 / F9 | 保存 / 读取 |
| Esc | 暂停、关闭界面、主菜单 |

## 开发

```powershell
.\run_editor.ps1
.\run_game.ps1
.\run_tests.ps1
.\run_stress_test.ps1
.\run_playtest.ps1
.\build_release.ps1
```

`run_playtest.ps1` 会打开真实游戏窗口，按玩家输入完成 41 个操作步骤；`build_release.ps1` 将其作为发布门禁。

正式数值统一在 `data/*.csv`。构建脚本同步 `.csv.txt` 供导出 PCK 读取，不要单独修改副本。
