# 2. 顶层设计铁律（所有开发必须严格遵守，决定游戏好不好玩的核心）
## 2.1 充分借鉴成熟爆款经验，拒绝闭门造车
所有玩法设计必须基于已被市场验证的成功经验，核心框架深度复用《星露谷物语》与《潜水员戴夫》的成熟设计逻辑，不凭空自创晦涩、反直觉的机制，从根源上保证游戏性。

### 重点吸取《星露谷物语》核心优势
1. **舒适低压力循环**：每日节奏清晰，付出即有正向反馈，无严厉失败惩罚，玩起来放松不焦虑，不会因为一次失误就崩盘
2. **多目标并行不强制**：赚钱、收集、社交、探索多条线并行，玩家可自由选择重心，没有唯一正确的“通关方式”
3. **操作极简零门槛**：统一交互逻辑，按键少，不用记复杂组合，新手五分钟就能上手，没有学习壁垒
4. **长线内容自然解锁**：新内容随着游戏进程自然出现，不搞突然跳级，不强制玩家查攻略才能继续
5. **无任务压迫感**：所有事件、剧情、目标都通过NPC、场景自然呈现，没有强制任务面板，没有红点催促
6. **数值稳定高鲁棒性**：固定物价体系，经济系统容错性强，不会因为玩家玩法不同就出现崩坏
7. **收集纯乐趣**：古物、鱼类等收集系统纯靠探索获得，不强制、不卡进度，是额外惊喜不是任务负担
8. **联机轻量合作**：好友联机纯合作、无对抗，不破坏单机体验，内容互通不独占
9. **小世界沉浸感**：聚焦小镇/社区尺度的精致世界，细节饱满、生活感强，不搞宏大的城市级模拟
10. **轻UI弱提示**：状态轻量展示、提示点到为止，不堆砌数值、不弹屏打扰，沉浸感优先
11. **职业深度养成**：每个职业有独立的成长线、技能树、阶段目标，长线有追求，日常有反馈

### 重点吸取《潜水员戴夫》核心优势
1. **强核心玩法闭环**：「探索→获取→经营→升级→更深探索」形成自洽的完整循环，环环相扣，每一步都有意义
2. **分段式内容解锁**：地图、玩法逐步开放，每一步都有明确的成长感，开局不堆砌海量内容造成玩家迷茫
3. **目标清晰反馈及时**：每一次行动都有明确收益，成长路径可见，不会让玩家不知道该干嘛
4. **玩法聚焦不臃肿**：核心玩法做到极致，附加内容服务于核心循环，不堆砌无关小游戏、冗余系统凑体量
5. **剧情自然推进**：事件随天数、进度自然触发，不是任务列表式发放，沉浸感强
6. **稀有度驱动收集**：不同深度、不同时段对应不同稀有度生物，概率驱动，有惊喜感，长线收集动力足
7. **经营养成爽感**：白天探索积累资源，晚上经营转化收益，收益反哺能力升级，正向循环停不下来

## 2.2 职业经营养成铁律：闭环成长·小步反馈·长线不枯燥
### 核心逻辑：每个职业/业态都要有自洽的成长闭环
参考戴夫「潜水抓鱼→开店卖寿司→赚钱升装备→潜更深抓更好的鱼」的强循环，所有职业、所有生意都遵循「日常投入→积累资源→升级能力/规模→获得更高收益」的正向闭环，拒绝单调线性涨工资、重复机械劳动。
- **每日有小反馈**：每天上班/开店都有即时收益、小事件、小变化，不会觉得干
- **阶段有大目标**：每段时间都有明确的成长方向（升职、扩店、解锁新渠道），有奔头
- **长线有深度**：技能、人脉、口碑、装备、渠道多维度养成，游戏寿命足够长
- **全程不强制**：所有成长都是自然发生，玩家可快可慢，可肝可闲

### 永久禁止的枯燥设计
- 禁止纯数值堆砌的升级：只涨数字不加玩法、只涨工资不加内容
- 禁止重复机械劳动：每天一模一样的操作，无变化无惊喜
- 禁止单一成长路径：只有一条路走到黑，无分支无选择
- 禁止无反馈干活：干半天不知道结果、努力了没动静

## 2.3 严格轻量化原则：拒绝臃肿，做深不做杂
1. **永远优先打磨核心循环，不盲目堆砌系统**
   核心玩法（生存→赚钱→成长）没打磨到位前，不新增边缘玩法、不扩充冗余系统、不堆大量支线凑时长。每加一个新系统，必须先验证它能让核心循环更好玩，而不是更复杂。
2. **所有新增内容必须服务于核心循环**
   每一个新场景、新职业、新玩法、新收集物、新联机功能、新经营细节，都要能融入主循环，要么提供成长动力，要么丰富体验层次；孤立无关、对核心循环没有增益的内容一律砍掉。
3. **分支做宽不做深，底层逻辑高度复用**
   人生路线数量多，但每条路线的底层逻辑复用统一框架（比如所有职业共用一套工作/晋升逻辑，所有店铺共用一套经营逻辑，只是数值、场景、剧情不同），不每条线单独做一套独立系统，避免代码和内容指数级膨胀。
4. **首发版本控制内容粒度**
   EA首发只保留核心3-4条主路线、3个核心城区、基础摸金收集体系、单机完整内容、基础经营玩法，联机模式及其余内容后续更新逐步加入，不追求一口气做“大全套”，避免项目臃肿烂尾。

## 2.4 易探索原则：拒绝解谜式卡关，所有内容自然可及
1. **无强制解密要素**
   不设置需要复杂推理、特定操作、查攻略才能触发的内容。所有玩法、彩蛋、收集点、联机互动都可以通过正常游玩、自然逛地图遇到，不搞“阴间触发条件”刁难玩家。
2. **成长路径清晰可见**
   职业晋升、区域解锁、技能升级、店铺升级的条件全部明确显示在对应面板上，玩家随时知道怎么达成，不藏条件、不搞隐形门槛，不会卡关。
3. **引导轻柔不强制**
   新手引导只教基础操作，后续内容通过场景提示、NPC对话自然引导；不强行牵着玩家走，也不会让玩家完全迷路。
4. **彩蛋/收集是惊喜不是任务**
   隐藏内容、稀有收集物是额外奖励，不是必须完成的目标；找不到也完全不影响主线体验，不卡进度、不锁玩法，避免玩家为了找彩蛋、凑收集产生焦虑。

## 2.5 操作极简原则：统一交互逻辑，降低学习成本
1. **全局统一交互逻辑**
   全程遵循“靠近+右键=交互”的万能规则，不管是开门、对话、上班、开店、使用物品、拾取物件、触发事件、联动物品交互，逻辑完全一致，不用切换操作方式。
2. **核心按键最少化**
   常用核心按键不超过10个，单手可操作，不设复杂组合键，不搞反人类操作；联机模式不新增额外复杂按键；经营界面一键操作，不用多层菜单。
3. **界面信息轻量化**
   UI只显示当前最必要的信息，不堆砌大量数据、不搞复杂仪表盘，避免玩家信息过载；联机界面仅显示队友基础状态，不占用大面积屏幕；经营界面只显示核心数据，不做复杂报表。
4. **所有操作有明确反馈**
   点击、交互、成功、失败、拾取到稀有物、联机互动、经营收益都有清晰的视觉/音效反馈，不用玩家猜有没有触发成功。

## 2.6 无任务化沉浸原则：拒绝网游式任务体系，全自然引导
### 永久禁止的传统任务元素（绝对不能出现）
- 禁止全局任务面板、任务列表、任务追踪栏
- 禁止NPC头顶感叹号、问号、任务标记
- 禁止自动弹出“你有新任务”“任务完成”提示
- 禁止红点提醒、每日任务、活跃度奖励、任务签到
- 禁止“接受任务→完成目标→提交领奖”的三段式逻辑
- 禁止强制主线任务、卡进度的必做任务
- 禁止收集进度红点提示、强制收集目标
- 禁止联机专属任务、强制组队目标
- 禁止经营类每日任务、强制订单、强制指标

### 核心设计逻辑：世界自己运转，玩家自行选择
1. **所有机遇与事件都是生活自然发生**
   游戏里的一切机会、剧情、变化，都像真实生活一样自然出现：房东上门收租、朋友喊你聚餐、店里来客人、街上有招聘告示、天气影响生意、角落刷出旧物件、好友约你出门、生意好坏自然波动。
   没有“系统给你派任务”的感觉，只有“生活里发生了一件事，你选怎么应对”。

2. **所有引导全靠环境与人际传递**
   玩家想做什么、能做什么、能捡什么、能玩什么，通过四种自然方式知晓，全程无系统直白告知：
   - **场景告示引导**：劳务市场墙上贴招聘、图书馆门口贴考试通知、公交站贴旅游线路、店铺门口贴招工启事。玩家自己逛、自己看，自己发现机会。
   - **NPC闲聊引导**：和街坊聊天随口提“最近工业区招工”“下雨天雨伞卖得好”“下个月有招聘会”“废品站最近能淘到好东西”；好感高了NPC会主动告诉你隐秘机会、介绍人脉、透露藏货点、推荐进货渠道。
   - **生活反馈引导**：房租扣钱了自然知道要赚钱，上班迟到扣工资了自然知道要早起，精力不够了自然知道要休息吃饭，生意差了自然知道要调整。所有规则通过结果反馈，不用新手教程长篇大论。
   - **街头传闻引导**：菜市场、便利店、公交站，路人对话里藏着各种信息、商机、八卦、淘货地点，路过就能听见，留心就能发现机会。
   - **好友邀约引导**：联机模式下，好友通过游戏内闲聊邀约一起开店、一起逛、一起旅游，自然触发联机玩法，无系统强制组队。

3. **目标由玩家自己定，系统不指派**
   没有“你必须打工赚钱”“你必须考大学”“你必须集齐所有收集物”“你必须把店开到满级”。
   游戏只提供完整的世界规则和可能性，玩家自己决定这辈子要过成什么样：想奋斗就去创业打拼，想安稳就去考公，想躺平就天天宅家，想淘货就逛遍全城角落，想和朋友玩就联机结伴，想开个小店就慢慢经营。
   所有成长都是自然结果：认真上班自然会涨薪升职，经常读书自然能考过试，常和人来往自然好感高，常逛角落自然能捡到稀有物，用心经营生意自然会好，不是“完成任务获得奖励”。

4. **成就与收集深度隐藏，不干扰核心体验**
   图鉴、成就、收集品只藏在个人状态面板的最深处分页，不主动提示、不弹红点、不强制完成。
   玩家完全不碰也能完整体验全部玩法，不会有任何缺失感；喜欢收集的玩家可以自己去挖，当成额外乐趣。

## 2.7 极简背包与合成原则：拒绝复杂库存管理，零合成负担
### 永久禁止的复杂逻辑（绝对不能出现）
1. 禁止复杂合成体系：禁止多级合成配方树、禁止材料组合解谜、禁止解锁配方图谱、禁止3种及以上材料合成一件物品
2. 禁止复杂背包逻辑：禁止负重上限、禁止格子不足、禁止频繁整理、禁止复杂分类筛选、禁止堆叠上限卡操作
3. 禁止强制加工环节：禁止收集物必须合成/加工才能使用、禁止原材料必须二次制作才能变现
4. 禁止碎片合成逻辑：不存在“收集N个碎片合成完整品”“零件拼装成品”的设计，所有拾取物均为完整可用状态
5. 禁止联机共享背包、共享仓库、复杂财务系统

### 极简执行标准
1. **背包系统：无感式管理**
   - 背包容量极大（近乎无限），全程无负重惩罚，捡东西永远装得下，无需取舍
   - 自动堆叠同类物品、自动按大类分区，无需玩家手动整理、手动排序
   - 打开背包一眼能找到目标物品，没有多层文件夹、没有复杂筛选条件
   - 出售、使用、赠送物品一键操作，无需拆分、无需批量确认
   - 摸金拾取自动归类到收藏分页，和日常消耗品、商品分开存放，互不干扰
   - 联机模式下各自背包独立，不共享、不互通，避免管理负担；跨存档进入他人世界时，可完整携带自身背包全部物品

2. **制作/合成逻辑：极致简化，能不做就不做**
   - 核心玩法不依赖合成，优先成品买卖，减少制作环节；创业以进货转售为主，不搞复杂生产链
   - 若保留制作功能，仅支持「1种原材料→1种成品」或最多「2种材料简单组合」，无复杂配方
   - 制作无需解锁配方，靠近对应工作台直接显示可制作物品，材料足够一键完成
   - 不设制作等级、不设制作熟练度、不卡配方进度

3. **收集物：即用型设计**
   - 所有摸金收集物拾取后直接可用、直接可送、直接可摆、直接可兑换，无需二次加工
   - 稀有物件直接触发对应效果、剧情、好感，不需要组合、不需要加工

## 2.8 经营机制原则：丰富但简单，拒绝模拟城市式复杂管理
### 核心定位：小店经营体验，不是城市供应链模拟
聚焦“一个小店的日常”，做深细节、做优体验，不扩大到城市级经济管理、不搞多级分销、不做复杂产业链。

### 永久禁止的复杂经营玩法
- 禁止多级供应商、供应链管理、物流调度
- 禁止员工排班、考勤、薪资谈判、人事管理
- 禁止店铺连锁扩张的复杂股权、分店管理
- 禁止市场竞争、价格战、竞品AI
- 禁止复杂财务报表、成本核算、税务系统
- 禁止数值化经营仪表盘、每日数据报表

### 丰富但简单的经营维度（全部一键操作、数值自动结算、体感化反馈）
1. **店铺等级**：从小摊→小店→标准店→精致店，升级仅解锁更多货架、更好客流、更高口碑上限，不新增复杂操作
2. **口碑系统**：服务好、货品全、无缺货，口碑自然上涨；口碑越高，随机客流越多，回头客概率越高，全部自动结算，不用玩家手动运营；通过“今天老客挺多”“生意不错”简单提示感知，不显示具体口碑分
3. **进货渠道差异**：不同批发市场、不同供货商，同样商品进价有小幅差异；远的市场便宜但费时间路费，近的方便但略贵，玩家自行选择
4. **淡旺季波动**：不同季节、不同天气、不同时段，对应品类销量自然波动，比如夏天水饮好卖、雨天雨伞好卖，全部自动生效；通过当日营收自然感知，不做数据对比
5. **简单陈列装扮**：店铺可自由摆放货架、装饰、小摆件，装扮影响店铺吸引力，小幅提升客流；纯视觉+小幅数值加成，操作简单
6. **常客系统**：常来的顾客会变成熟客，消费更稳定，偶尔带新客；自然积累，无需玩家维护

## 2.9 精致小世界原则：场景做精做细，不做庞大空洞
### 核心方向：聚焦市井尺度，打造有温度的身边小世界
不追求还原整个深圳的庞大地图，只做几片代表性的、充满生活气息的片区，把每个角落的细节、装扮感、生活感做足，让玩家觉得“这就是我住过的城中村/街边”，而不是一个空洞的城市沙盘。

### 场景精致化方向
1. **细节饱满**：街边的共享单车、门口的拖鞋、墙上的小广告、夜晚的霓虹招牌、路边的夜宵摊、下雨的水洼，每个场景都有大量生活化小细节
2. **装扮感强**：每家店有自己的招牌、装修风格；玩家的家、玩家的店可以自由换装饰、换布局，打造专属自己的小空间
3. **昼夜差异**：白天热闹市井、夜晚霓虹氛围感，不同时段场景状态不同，比如白天开店晚上关门、深夜只有夜宵摊亮灯
4. **天气呼应**：下雨有雨丝、地面积水、行人打伞；回南天墙面潮湿；酷暑阳光刺眼，场景视觉随天气变化
5. **生活气息**：场景里有动态的NPC走路、买菜、聊天、上班下班，不是静态的背景板，是活着的小世界

## 2.10 联机设计原则：轻量合作·无对抗·不破坏单机
1. **纯合作无对抗**：全程PVE合作，无PVP、无竞争、无抢资源、不对抗，主打朋友一起轻松玩
2. **单机内容完全体**：所有玩法、内容、场景、收集物单机模式全部可体验，无联机独占内容，不强制玩家联机
3. **轻量化不复杂**：不搞公会、帮派、大型多人；最多4人小规模好友联机；不做复杂经济共享、复杂权限系统
4. **不改变核心规则**：固定物价、无任务、极简背包、零合成、简单经营等所有核心规则，联机模式完全沿用，不新增特殊机制
5. **跨存档携带与交易**：玩家进入他人存档时，可完整携带自身背包内的所有物品；支持玩家间物品赠送、以物易物、金钱交易，交易规则简单

## 2.11 全感知无面板原则：所有状态体感化，禁止数值属性面板
### 永久禁止的数值面板设计（绝对不能出现）
- 禁止王者荣耀式属性面板、禁止垂直/水平数值血条/精力条/情绪条
- 禁止显示具体数值：如“精力75/100”“健康90”“幸运值50”“口碑80分”
- 禁止堆叠状态图标：一排buff/debuff图标常驻屏幕角落
- 禁止复杂计算界面：经营数据报表、属性加点面板、数值对比界面
- 禁止精确数字提示：所有状态、效果、增益都用口语化模糊描述，不用精确百分比

### 核心设计逻辑：像真实人一样感知状态，不靠系统读面板
玩家对所有状态、变量、效果的感知，全部来自**视觉表现、角色动作、事件结果、简短弱提示**，和现实生活中感知自己状态的方式一致——你不会看到自己的“精力值”，只会觉得累、走不动、想睡觉；你不会看到“口碑分”，只会觉得今天客人特别多。

### 全感知实现标准
#### 1. 身体状态类（精力、健康、疲惫）
- **视觉感知**：疲惫时画面略微变暗、边缘发虚；生病时画面偏冷色、轻微模糊；精力充沛时画面明亮通透
- **动作感知**：精力充足走路轻快；疲惫时步速变慢、身体微躬、偶尔扶额头；生病时走路更慢、咳嗽小动作
- **弱提示**：只有状态快到临界值时，才会出现一行小字弱提示“有点累了，歇歇吧”“好像感冒了”，不常驻显示，提示后自动消失
- **无数值**：全程不显示精力值、健康值，玩家靠体感判断状态

#### 2. 情绪类（开心、压抑、孤独、甜蜜）
- **视觉感知**：心情好时画面色调偏暖、轻微提亮；压抑时画面偏冷、饱和度降低；恋爱时画面带柔和光晕
- **动作感知**：开心时走路带跳步、偶尔吹口哨；低落时走路迟缓、低头；独处久了会踢石子小动作
- **事件感知**：心情好时遇到好事概率高、对话更积极；低落时社交效果差、做事效率低，通过结果反向感知情绪
- **无面板**：全程不显示情绪值、情绪条，完全靠画面和事件感知

#### 3. 隐藏属性类（幸运、口碑、人缘）
- **完全隐藏数值**：幸运值、口碑值、人脉值全程不显示、不提示
- **结果感知**：玩家只能通过事件结果感知——今天捡了好东西=运气不错；今天客人多=口碑好；NPC主动帮忙=人缘好
- **无任何界面**：没有任何面板、图标、提示显示这类属性，完全隐性影响游戏

#### 4. 经营类（客流、口碑、收益）
- **直观感知**：客人多不多一眼就能看到，赚了多少钱直接显示总额，不做细分报表
- **简单提示**：打烊后弹出一句总结“今天生意不错，赚了XXX”“今天人有点少”，无复杂数据
- **无经营仪表盘**：不做日销、周销、同比、环比，不堆数据面板

#### 5. Buff/Debuff效果类
- **触发时弱提示**：获得/失去效果时，屏幕中间偏下出现一行简短文字提示，2秒后自动消失，不常驻图标
- **效果体感化**：效果全部通过画面、动作、事件结果体现，不做图标常驻、不做数值说明
- **无状态栏**：没有buff栏、debuff栏，玩家自己记住效果，系统不持续提醒

# 3. 核心固定规则（永久锁死，禁止改动）
1. **经济系统：固定物价为基础，细节丰富不颠覆（星露谷标准）**
   - 所有商品官方基准买入、卖出价格永久固定写死，无自由浮动、无通胀通缩等等……
   - 在此基础上丰富细节：不同渠道进货价有±5%-10%的小幅差异、批量进货有小额折扣、淡旺季销量有波动等等……
   - 无宏观经济仿真、无供需崩盘、无城市级经济模拟等等……
   - 允许玩家后期自动化流水线赚钱、合理暴富等等……
   - 经营差异只来自：客流、口碑、服务、进货成本、事件波动、店铺装扮等等……
   - 稀有收集物有固定收购价，但价格偏低，不作为核心赚钱手段，仅作收集副产品，不破坏经济平衡等等……
   - 联机模式完全沿用基准物价，玩家间交易可自行议价，但无系统强制定价，不影响整体经济平衡

2. **仅保留轻度安全动态（不增加开发难度）**
   - 节假日客流暴涨、淡季客流减少等等……
   - 雨季物流成本上涨、恶劣天气经营受限等等……
   - 阶段性招工潮、失业潮、行业热度变化等等……
   - 短期随机商机、短期亏损期、随机运气事件等等……
   - 收集物每日随机刷新、稀有物概率刷新，不做固定点位固定产出等等……
   - 店铺口碑、客流自然波动，不做剧烈变动
   - 联机组队仅带来小幅概率增益，不破坏原有数值平衡

3. **内容审核绝对安全底线（永久遵守）**
   - 可写实：租房难、求职难、打工累、生活压力、普通人不易、市井淘货捡漏、好友结伴打拼、小店经营不易等等……
   - 必须正向：努力有回报、选择改命运、人生可翻盘、无彻底绝望剧情等等……
   - 禁止：黑化叙事、制度批判、暴力冲突、灰色产业最优解、极端负面剧情、违法违规收集题材等等……

# 4. 【超级核心】千条无限人生自由分支体系（全覆盖现实人生·全职业闭环养成）
> 设计遵循：分支做宽不做深，底层逻辑复用；所有路线入口自然可见，玩家可随时切换，不卡关、无任务触发、无复杂合成门槛；每个职业/业态都有独立成长闭环，日常有反馈、阶段有目标、长线有深度

## 4.1 学业升学路线（无限拓展）
玩家可自由选择：
- 全职备考、专升本、本科进修、**考研、读研、考博**等等……
- 海量证书考取：驾驶证、英语四六级、计算机二级、会计、教师资格、技能证书、行业资格证等等……
- 泡图书馆、自习室刷题、挂科、补考、学业逆袭、学渣躺平等等……
- 学历分层解锁高阶岗位、高薪工作、高端人脉、城市权限等等……
> 成长闭环：「投入时间学习→积累知识/学历→解锁更好的工作/更高的薪资→获得更多资源/时间→继续深造」
> 自然入口：图书馆门口的考试公告、书店里的备考资料、朋友聊天提到的升学路径
> AI可自主新增：各类专业细分、各类考试、各类校园生活剧情

## 4.2 体制稳定路线
- 考公、考编、事业单位、国企应聘、稳定岗位晋升等等……
- 朝九晚五、低风险、稳定薪资、慢速成长、安稳人生等等……
> 成长闭环：「认真工作→积累资历/人脉→稳步晋升/评优→收入提升、福利变好→更安稳的生活」
> 自然入口：政务公告栏的招聘信息、长辈NPC的推荐、人才市场的单位展位
> AI可自主新增：不同岗位体制生活、基层日常、晋升细节

## 4.3 职场打工路线（全职业覆盖·分岗位闭环养成）
> 核心设计：每个岗位都有独立的日常内容、成长路径、乐趣点，拒绝统一打卡上班领工资的枯燥模式；参考戴夫的探索-经营循环，每个职业都是「投入精力→积累资源→升级能力→更高收益」的闭环

### 流水线工人
- **日常做什么**：到岗打卡、工位操作、完成当日产能、偶尔加班赶单、中途休息吃饭
- **成长闭环**：「熟练操作→产能提升→计件工资变多/评优秀员工→涨薪/升组长→管理产线赚更多」
- **乐趣与变化**：
  - 手速快了产量高，多劳多得，当天就能看到工资涨
  - 遇到赶货期加班有双倍补贴，也可以选择不加
  - 和工友处好关系，有人帮你分担活，干得更轻松
  - 表现好升组长，不用自己干，管产线拿管理工资
  - 随机事件：设备故障、物料延误、组长抽查、工友聚餐
> 自然入口：工厂门口的招工启事、劳务市场招聘
> AI可自主新增：更多细分工种、车间事件、晋升路径

### 普通文员/前台
- **日常做什么**：到岗打卡、处理文件、接待访客、整理内务、摸鱼划水、偶尔加班
- **成长闭环**：「做事靠谱→积累好评→升行政专员/主管→薪资提升、工作更轻松→更好的职场机会」
- **乐趣与变化**：
  - 活少的时候可以偷偷摸鱼，看剧、刷题、搞副业，不影响工资
  - 接待好重要访客、搞定难搞的文件，会有额外奖金
  - 和同事关系好，有人帮你顶锅、帮你带饭、帮你打卡
  - 熬资历升主管，管人事管行政，权力大时间多
  - 随机事件：临时通知开会、客户突然到访、同事请假代班、下午茶团建
> 自然入口：写字楼招聘启事、朋友内推

### 销售岗
- **日常做什么**：到岗打卡、跑客户、谈订单、维护客情、冲业绩、拿提成
- **成长闭环**：「积累客户→订单变多→提成收入暴涨→升销售主管/经理→带团队拿团队提成」
- **乐趣与变化**：
  - 开单当天就能拿提成，收入上不封顶，爆单的时候特别爽
  - 搞定大客户直接拿大额奖金，一步翻身
  - 客户积累多了，老客自动返单，躺着赚钱
  - 升销冠、升经理，带团队吃团队业绩，收入更高更轻松
  - 随机事件：客户爽约、天降大单、同行抢单、客户请客
> 自然入口：门店招聘、人才市场销售岗

### 技术岗
- **日常做什么**：到岗打卡、写代码/做设计、改需求、解bug、项目上线、偶尔熬夜
- **成长闭环**：「提升技术→搞定难项目→涨薪/评级→升技术主管/架构师→更高薪资+技术话语权」
- **乐趣与变化**：
  - 攻克技术难题、项目顺利上线，直接拿项目奖金
  - 技术练熟了，效率越来越高，上班越来越轻松，还能接私活
  - 能力强了可以跳更好的厂，薪资跳级涨
  - 升技术管理，带项目带团队，收入翻倍
  - 随机事件：需求临时变更、线上出bug、项目加急、技术分享会
> 自然入口：互联网公司招聘、招聘网站信息

## 4.4 创业经商路线（丰富简单经营机制·分业态闭环养成）
> 核心设计：每种业态都有「进货/备货→经营售卖→赚钱升级→更大规模/更好货源→赚更多」的完整闭环，从小摊到小店到工厂，步步有目标，天天有反馈，经营有乐趣，不枯燥；参考戴夫寿司店的经营-升级循环，每个阶段都有新玩法新目标

### 地摊摆摊（起步级）
- **日常做什么**：选品类、去批发市场进货、占摊位、出摊、卖货、收摊、盘点当日收益
- **成长闭环**：「选对品类→卖得快赚得多→攒资金/攒口碑→换大摊位/进更好的货→利润更高」
- **经营乐趣点**：
  - 选对品类（比如夏天卖水、雨天卖伞），销量暴涨，当天就能多赚钱
  - 占个好位置，客流大卖得快，位置差就冷清
  - 摆久了有熟客，常来光顾还带朋友
  - 慢慢攒够钱，可以换大摊位、卖更多品类，收入翻倍
  - 随机事件：城管巡查（合规摆摊仅提醒，无暴力冲突）、同行抢位置、熟客带新客、批发商临时降价
> 自然入口：摆摊同行闲聊、批发市场招租

### 小吃/饮品店（进阶级）
- **日常做什么**：备食材、开门营业、做餐出餐、接待顾客、打烊盘点、进货补货
- **成长闭环**：「口味做好→口碑上涨→客流变多→赚更多钱→装修店铺/加品类→生意更好」
- **经营乐趣点**：
  - 饭点高峰期忙不过来，卖得多赚得多，闲的时候可以休息
  - 新品上市吸引新顾客，爆款单品带飞全天营收
  - 店铺装修好看了，客人愿意来，客单价也能涨
  - 雇个店员帮忙看店，自己可以去跑货源、搞别的事
  - 随机事件：美食博主探店突然爆火、食材涨价、熟客办卡、差评风波
> 自然入口：商铺招租告示、同行推荐

### 零售百货店（规模级）
- **日常做什么**：选货源、进货铺货、理货、接待顾客、收银、盘库存、维护口碑
- **成长闭环**：「品类齐全→客流稳定→利润稳定→升级店铺/扩面积→更多品类更高营收」
- **经营乐趣点**：
  - 找到低价货源，差价大利润高，赚钱更轻松
  - 位置好客流大，薄利多销走量也能赚很多
  - 口碑做起来了，周边居民都来买，生意稳定
  - 开成连锁便利店，雇店长管理，躺赚分红
  - 随机事件：供应商清仓甩货、竞品打折、节日促销爆单、临期商品处理
> 自然入口：商圈商铺招租、批发市场渠道

### 小型加工厂（高阶）
- **日常做什么**：进原料、安排生产、管工人、跑销路、出货收款、设备维护
- **成长闭环**：「产能提升→批量出货→赚更多钱→升级设备/扩产→规模效应利润更高」
- **经营乐趣点**：
  - 接到大订单，批量出货，一次性赚大钱
  - 设备升级了，产能高人工少，成本更低
  - 积累稳定客户，订单源源不断，躺着赚钱
  - 做自有品牌，溢价更高，生意更稳
  - 随机事件：原料涨价、订单加急、设备故障、查厂安检
> 自然入口：工业区厂房招租、行业人脉介绍

> 设计原则：以成品进货转售为主，不搞复杂生产合成；经营维度丰富但操作极简，右键一键搞定，不做复杂管理界面
> 经营体感：客流多少看场景里的人数，赚了多少看结算数字，口碑好坏看回头客多少，不用面板看数据
> AI可自主新增：各类小店业态、小众创业项目、季节性生意、更多经营细节、每个业态的专属事件与升级路径

# 6. 城市摸金与稀有收集系统（概率驱动·自然探索·无任务强制·零合成）
> 设计对标：星露谷物语古物/钓鱼收集 + 潜水员戴夫稀有鱼系统；纯探索乐趣，不强制、不卡进度、不破坏经济
> 核心规则：全城各类点位每日随机刷新物件，分4级稀有度对应不同概率；玩家逛到就能捡，逛不到也不影响任何玩法；收集物主打收藏、解锁、好感，不以卖钱为核心；所有物品拾取即用，无合成、无加工；联机模式下资源不冲突，每人独立掉落

## 6.1 稀有度分级与概率规则（全局统一标准）
所有收集物按稀有度分为4级，每个刷新点位有独立的掉落池和对应概率，每日凌晨自动刷新：
1. **普通（60%概率）**：常见废品、日常小物件、空瓶子、废纸、旧塑料等等……
   - 可卖少量零钱，可回收换钱，无特殊价值
2. **少见（25%概率）**：旧玩具、老杂志、旧工具、完整餐具、旧唱片等等……
   - 可卖普通价格，部分NPC喜欢，可小幅提升好感
3. **稀有（12%概率）**：老物件、复古饰品、稀有零件、绝版书籍、旧相机等等……
   - 固定收购价不高，但可解锁特殊进货渠道、可兑换专属道具、大幅提升特定NPC好感
4. **传说（3%概率）**：绝版纪念物、老古董、稀有藏品、限定徽章、神秘信物等等……
   - 数量极少，全游戏仅个位数；解锁隐藏剧情、隐藏场景、专属成就；无法通过购买获得
> AI可自主新增：更多稀有度细分、更多概率梯度、特殊限定稀有物等等……

## 6.2 核心摸金收集场景（自然分布，全地图探索）
所有刷新点融入城市场景，没有特殊标记，玩家靠近才能看到闪光点提示，不逛就不会发现
1. **街头巷尾随机刷新点**
   - 分布：城中村角落、纸箱堆、废品堆、墙根、树下、公交站旁等等……
   - 刷新规则：每日凌晨刷新，每点刷1件，普通概率最高
   - 交互方式：靠近右键拾取，消耗少量体力，自动进背包收藏页
   - 特点：遍布全城，随手可捡，积少成多，适合闲逛时顺路摸金
   - 联机：各自独立刷新，互不干扰，组队小幅提升稀有概率

2. **旧货市场/跳蚤摊位**
   - 分布：城中村集市、周末跳蚤市场
   - 刷新规则：每日刷新库存，每件商品明码标价（固定物价基准），有概率刷出稀有/传说物件
   - 交互方式：花钱购买，纯淘货玩法，考验眼力
   - 特点：不用翻废品，花钱赌运气，适合有一定积蓄的玩家

3. **废品回收站翻找**
   - 分布：工业区边缘、城中村废品站
   - 刷新规则：每日刷新大量废品，消耗体力翻找，概率产出各等级物件
   - 交互方式：右键开始翻找，消耗体力，随机获得1-3件物品
   - 特点：体力换概率，体力越多翻得越多，适合前期没钱靠力气淘宝

4. **工地废弃区**
   - 分布：工业区工地角落、废弃建材堆
   - 刷新规则：解锁工业区后开放，每日刷新，产出旧工具、建材、稀有金属零件
   - 交互方式：消耗体力翻找
   - 特点：产出的工具、零件可直接用于店铺维修、设备升级，实用价值高

5. **隐藏藏宝点**
   - 分布：全城隐秘角落：老树下、墙洞、废弃房屋、楼顶、下水道入口等等……
   - 刷新规则：固定点位，每个档仅1件稀有/传说级物品，捡到永久消失
   - 交互方式：探索发现后右键拾取
   - 特点：纯探索彩蛋，位置隐秘，需要玩家细心逛地图才能发现

6. **节日/季节限定收集物**
   - 分布：节日期间的特定区域
   - 刷新规则：仅春节、端午、中秋、国庆、双11等节日限时刷新，错过等一年
   - 特点：限定稀有度，收藏价值高，对应节日专属彩蛋

7. **旅游景区专属收集物**
   - 分布：各旅游景点
   - 刷新规则：旅行时可拾取，景区专属，城区无法获得
   - 特点：旅游图鉴配套，纪念意义大于实用价值
> AI可自主新增：更多收集场景、更多刷新点位、特殊联动收集点等等……

## 6.3 收集物核心用途（不破坏经济，服务核心循环，即用型）
1. **图鉴收藏**
   - 全部收录进个人收藏图鉴，分门类展示，纯收集成就，满足收集癖玩家
   - 图鉴隐藏在状态面板深处，无红点、无强制完成提示

2. **NPC专属好感礼物**
   - 每个NPC有自己的喜好，对应特定稀有物，赠送后好感度大幅提升，远超普通礼物
   - 部分隐藏NPC只有送对应稀有物才会解锁对话和剧情

3. **实用功能解锁**
   - 旧工具：提升维修效率、减少店铺设备损耗
   - 稀有零件：解锁店铺设备升级、自动化改造
   - 特殊信物：解锁隐藏进货渠道、专属商品、低价货源

4. **家居装饰**
   - 稀有物件可摆放在家里、店里，提升居住环境/店铺吸引力，小幅提升情绪恢复速度/客流

# 7. 联机合作模式（后续更新·轻量好友向·纯合作无对抗·跨存档带物交易）
> 设计定位：作为EA版本后首个大型更新，主打好友共同体验，复刻现实里朋友一起在大城市打拼的生活感；纯合作、无对抗、不强制、不破坏单机体验，所有内容单机均可完整游玩
> 核心规则：沿用全局所有核心设定（固定物价、无任务、极简背包、零合成、简单经营、全感知），仅新增多人互动与合作增益，不新增独立复杂系统；支持跨存档携带背包物品，支持玩家间交易

## 7.1 联机核心玩法（2-4人小规模好友联机）
### 7.1.1 合租共建生活
- 玩家可共同租赁更大的户型（单间→两室一厅→三室两厅），房租、水电平摊，人均生活成本降低
- 房屋公共区域共同装修、共同摆放收集物与家具，私人区域各自布置
- 可一起做饭、一起休息，情绪恢复、精力恢复效率小幅提升
- 互相串门、临时借住，好友到访有专属互动

### 7.1.2 合伙创业经营
- 可共同出资开设店铺，支持简单分工：一人看店经营、一人进货跑渠道，也可两人同时看店提升客流效率
- 利润按约定比例自动分配（默认平摊，可提前设置），不做复杂股权、财务报表，轻量化处理
- 合伙店铺可解锁更大的店铺规模、更多货架，单人模式也可独立解锁同等级店铺，无联机独占
- 一起跑市场、一起淘货，进货时有小概率拿到额外赠品
- 店铺装扮可共同布置，也可各自摆放自己的装饰物件

### 7.1.3 结伴探索摸金
- 组队逛城市、一起翻废品、一起淘旧货，队伍运气小幅叠加，稀有物刷新概率轻度提升
- 隐藏藏宝点可共同触发，奖励每人各一份，不抢资源
- 一起旅游出行，解锁专属组队随机事件，旅途体验更丰富
- 通勤结伴，降低通勤意外概率，不会单独遇到晚点、拥堵

### 7.1.4 职场与社交互动
- 可入职同一家公司，一起上下班，职场好感提升更快，互相帮忙提升绩效
- 一起聚餐、一起参加社交活动，人脉积累效率提升
- 互相赠送礼物、收集物、商品，好感提升效率高于普通NPC

### 7.1.5 跨存档带物与玩家交易
- **跨存档携带机制**：玩家从自己的存档退出，选择加入好友的存档时，可完整携带自身背包内的所有物品（消耗品、收集物、商品、金钱），角色属性、技能、学历也一并保留
- **物品交易机制**：靠近队友右键选择交易/赠送，可直接赠送物品，也可发起交易：双方放入物品/金钱，确认后完成交换；支持以物易物、金钱购买、混合交易
- **交易规则**：无手续费、无税收、无系统限制价格，玩家自行协商；基于固定物价基准，玩家间可自由议价，不影响全局经济系统
- **安全机制**：交易需双方确认，防止误操作；赠送有二次确认，避免错给
- **无交易面板堆砌**：交易界面极简，只有双方放物品的格子和确认按钮，不做复杂交易记录、账单

## 7.2 联机基础规则（严格遵守，避免复杂化）
1. **个人资产相对独立**
   - 金钱、背包、技能、学历、属性、图鉴全部各自独立，不共享、不通用
   - 合伙店铺仅共享经营收益，个人财产严格分离，无复杂财务纠纷
   - 无公共背包、无共享仓库，避免整理负担
   - 跨存档进入他人世界，仅带走自身物品，不影响房主世界的资源

2. **核心规则完全沿用**
   - 固定物价体系不变，无联机专属商品、无联机专属价格
   - 无任务体系，无联机专属任务、无强制目标、无红点提醒
   - 极简背包逻辑不变，无负重、无格子限制、自动堆叠
   - 零合成设定不变，所有物品拾取即用，无联机专属合成
   - 简单经营机制不变，不新增联机专属复杂管理玩法
   - 全感知无面板原则不变，不新增联机专属数值面板

3. **进度与存档规则**
   - 世界进度由房主保存，加入玩家的角色数据独立保存，离开时带走自身全部属性、物品、金钱
   - 可随时加入、随时退出，不影响房主世界进度，也不损失自身角色进度
   - 支持断线重连，短时间断开自动重连保留状态
   - 玩家自身的角色存档独立，可在任意存档间切换，物品随身带

4. **人数与权限规则**
   - 最多支持4人同时联机，小规模好友向，不搞大型公共房间
   - 房主拥有世界控制权，可踢人、可设置加入权限；其他玩家仅操作自身角色
   - 无陌生人匹配，仅支持好友邀请联机，主打熟人社交

## 7.3 联机专属增益（仅小幅加成，不碾压单机）
- 合租：人均房租降低，精力恢复速度提升

> 所有增益仅为小幅体验优化，单机模式完全可以正常游玩，无强度碾压
> 所有增益通过效果自然感知，不显示具体百分比数值

## 7.4 设计底线（永久遵守）
1. 绝对不做PVP、对抗、竞争、抢资源玩法
2. 绝对不做联机独占内容、独占道具、独占场景、独占剧情
3. 绝对不增加复杂的公会、帮派、任务、成就系统

## 7.5 技术实现方案（善用成熟工具，不从零开发）

# 10. 游戏完整【玩家操作总细则｜全局按键｜交互逻辑｜触发机制】
## 10.1 全局固定按键（永久不变、极简上手）
- **WASD**：角色移动（全城通用、室内外通用、联机通用）
- **鼠标右键（核心万能键）**：交互、对话、开门、睡觉、上班、点餐、进货、摆摊、拾取物件、触发彩蛋、联动物品交互等等……

- **鼠标滚轮**：缩放游戏视角大小
- **I键**：打开背包/物品栏
- **M键**：打开大地图、查看已解锁区域、查看天气、查看日期、查看队友位置
- **C键**：打开个人面板（技能、学历、人脉、收藏图鉴、成就）

> 注：个人面板**不显示任何状态数值、属性条**，仅存放功能性内容（技能、图鉴、成就）

## 10.2 游戏核心交互规则（强制统一）
1. **所有交互必须“靠近才可触发”**
   禁止隔空交互、禁止远距离点物品触发；收集物必须走到旁边才能拾取；队友交互必须靠近才能触发
2. **右键万能统一逻辑**
   对着什么就是什么功能：
   - 对着床 = 睡觉
   - 对着店铺NPC = 购买/打工
   - 对着工作台 = 制作
   - 对着摊位 = 摆摊经营
   - 对着路人 = 对话/送礼/社交
   - 对着地上物件 = 拾取
   - 对着队友 = 互动/邀约/赠送
