# 《深城日常》0.4.0 场景经营 · 日历季节版

本版把经营从“表格”搬回街区里，并让时间、日历与摸金更像真实生活。

## 1. 摸金改成彩蛋式偶遇

- 地图上不再每天固定刷新旧物点，也没有专门为了摸金的场景。
- 只有很小概率会在日常里碰见旧物：出餐、卖货、上班、街上闲走、旧址探索。
- 每次偶遇配一句当时情境的叙事文案，而不是统一提示。
- 每天最多偶遇几次，避免刷屏；节日和夜晚会略微提高机会。
- 旧物图鉴集齐后仍可能捡到重复旧物，只是不再算首次发现。

## 2. 时间流速放慢

- 现实 1.1 秒对应游戏 1 分钟（旧版为 0.4 秒）。
- 一整天在现实中约 26 分钟，出门、经营、闲逛都不再手忙脚乱。
- 旧址探索仍会单独放慢生活时间，回到地面恢复。

## 3. 日历、节日、季节

- 全新年历系统：年、月、日、星期、季节都会推进。
- 年内 13 个节日（元旦、春节时段、劳动节、中秋、国庆、双十一、跨年等）。
- 节日会提高客流量与旧物出现机会，HUD 日历面板会提示“营业加成”。
- 四季会在场景里留下痕迹：春花瓣、夏光斑、秋落叶、冬细雪。
- 画面整体色调随季节变化，旧货行情与天气继续每日变化。

## 4. 餐馆与批发变成真实场景

- 夜市餐馆里有可走动的灶台工位、出餐台、餐桌、扩店告示和招工牌。
- 批发市场里每个货箱都可以直接点击进货，旁边有实体收购台。
- 所有升级、库存与利润变化都能在场景里看到，不再只存在于表格面板。
- 补上上一版遗留的两个未完成场景函数，工程可正常编译运行。

## 验证

- 自动冒烟测试、100 次 30 日经济压力测试全部通过。
- 餐馆与批发实体场景结构检查通过。
- 餐馆与批发“走得到、点得动”操作检查通过。
- 真实窗口玩家操作 Playtest：49 步全部通过。
- 完整经营与收集模拟：集齐全部 24 件旧物，总资产超过 5 万。
