# 《深城日常》0.3.0 深夜食堂经营版

这一版把“赚钱”做成了独立的核心玩法，不再只是打工领工资。

## 经营循环

1. 脑力、劳力每天恢复，也可以花钱应急补充。
2. 到批发市场买食材，价格每天变化；买低卖高可以赚差价，也可能看错行情亏损。
3. 在夜市档口接订单，给空闲工位放入菜品配方。
4. 每个工位经历备料、下锅、装盘三个阶段，每个阶段都需要玩家点击推进。
5. 菜品完成后上给对应客人，获得营业收入与连击奖励。
6. 食材、劳力和脑力都在开工时真实扣除，缺货或缺人会导致工位停摆。
7. 用利润扩大档口、增加工位与库存容量，菜单也会逐步扩大。
8. 生意达到规模后可以转让铺子，获得大额回报和稀有纪念物。

## 资金系统

- 银行支持存款、取款与每日活期利息。
- 彩票有低概率高额奖励和多种小额奖项，长期期望偏亏。
- 商品库存记录平均进货成本，随时原价卖出可以计算真实盈亏。
- 菜品收入、买卖差价、银行利息、彩票支出和月租分别记账。

## 旧址与经济

旧址入口不再依赖装备，而由累计成交、摊位规模和熟客口碑解锁。探索带回的旧物可立即出售或寄卖，资金再投入夜市档口，形成完整循环。

## 验收

- 完整经营与收集模拟会循环打工、进货、做菜、出餐、买卖、存款、利息、彩票和旧址探索。
- 直到 24 件旧物全部收集且总资产达到 5 万以上才判定通过。
## 交互修复

- 经营界面不再周期性销毁按钮，鼠标按下期间按钮保持稳定。
- 出餐工位与菜单按钮采用状态文本更新，不再影响点击。
- 桌面新增“深城日常_最新版.exe”，每次发布构建都会覆盖为最新版。
