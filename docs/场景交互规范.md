# 《深城日常》场景交互规范（人才公园餐馆先行）

更新：2026-09-28。近期只验收深圳湾人才公园湖畔一间餐馆的九个固定工作台操作、排队顾客、十菜、备货和打烊前持续营业，以及果茶、海风杯、长椅和独立存档。跑单、创作与其他城市留待后续。新版与旧 2D 从入口、菜单、存档分开。

## 操作与画面约束

1. **公园行走与工作分镜**：新版启动直接进入持续营业的厨房；玩家也可自愿退出到公园自由行走、转动镜头，再点击餐馆入口回来。厨房里用鼠标直接点食材、设备、订单票和顾客，完成菜直接点成品交餐；旧班铃与独立出餐台不再出现。厨房镜头允许滚轮缩放、左键按住拖动画面或方向键平移、右键拖动调整角度，Home 还原全景；物件在放大与转角后仍需保持可点击。
2. **物件承载信息**：顾客在窗口排队，订单票给菜盘图和耐心条；原料、半成品、加热和成品用可辨的实物模型或图形表示。操作中不以文字句子提示下一步，也不把文字贴在地图表面。必要的现金、秒数、数量和设置可显示数字或简短文字；悬停说明可作无障碍辅助。
3. **每个动作有反馈**：清洗、切配、搅拌、腌制、分装、蒸制、煎制、煮制、点缀、交餐分别驱动设备、食物或顾客的可见变化。备料助手在备货后接收半成品，取餐店员在出餐后到窗前取走这单的具体菜品，再由服务通道送出；订单即刻补位时不能把旧菜递给新顾客。最后一单完成后保持厨房开放，可直接开下一班。角色手臂、裤腿各是一条连贯形体，不用三颗球串成四肢，裤脚与鞋自然衔接，服饰和发型不要堆细碎球形配件。加热有蒸汽与就地进度，临近烧焦有警示，烧焦有黑烟与食物变色，交餐有餐铃与收银反馈，失败有顾客离开和连击中断；常规动作不弹说明卡。
4. **两档节奏**：悠闲班有宽松顾客耐心；忙碌班第三位顾客在不同班次的不同时刻加入，可能有短耐心高报酬急单，出餐更快、收入潜力更高。工作视角固定便于快速点选；离开厨房、暂停与切出窗口需保存并冻结或继续对应计时，不可出现隐形耗时。
5. **失败可恢复**：错放、超时、交错对象影响本单质量或收入，可拿回、重做或继续下一单；不产生债务、不可逆死局，也不因玩家休息触发惩罚。
6. **地图与相机**：本次可在人才公园与后海商圈地标范围行走，旋转斜俯视镜头，从店前缩放到区域总览。场景以 1 米对应 1 单位为目标，当前相对布局依据官方导览图比例推定，尚未经精测，不能声称严格 1:1；全深圳与大湾区通行留待后续。
7. **餐厅空间**：电脑及平板的大视窗要能看到完整的备料区、出餐窗、顾客等候区与有生活气息的餐厅陈设。台面留出明确的点击空间和视觉层次；宽屏扩展背景场景而不是拉大按钮、堆菜单或让订单票遮住锅具。

## 共用的现场任务状态

`可接 → 已接 → 进行中 → 可交付 → 已结算`，另有 `暂停/放弃`。每次对象交互产生 `{对象 id, 动词, 当前手持物, 世界位置}` 事件，由职业状态机验证并推进；HUD 只展示状态，不决定对错或发钱。目标对象消失、跨块加载或读档后，任务仍能按稳定对象 id 恢复。只有结算点写入金钱和职业记录，避免重复点击刷收益；当前餐馆试玩不消耗体力。

餐馆订单定义：菜品 id、原料图形 id、最多六个动作、半成品可替代的步骤、顾客耐心、加热时间与防烧焦窗口、基础报酬、速度小费和连击小费。计时以玩家实际操作推进；工作视图只读取状态并播放反馈，结算只由规则引擎发出一次。

## 餐饮经营：固定台面、双票并行、备货

| 环节 | 场景对象与玩家动作 | 状态与即时反馈 |
|---|---|---|
| 接班 | 点击店门口的悠闲/忙碌班铃 | 切入固定厨房视角，顾客入队，出现两张图形订单票 |
| 选单 | 点击票或排队顾客 | 将该单置为当前制作目标；加热等待时可处理另一单 |
| 十种操作 | 点击工作台对应实体设备与食材 | 依菜谱使用清洗、切配、搅拌、腌制、分装、蒸、煎、煮、点缀、交餐；每菜实际四至六步 |
| 半成品 | 点击米浆或香料油保鲜架，再点台面完成两步备货 | 每批两份，合计容量五份，有鲜度倒计时；匹配的菜在起始可点货架取一份跳过前两步 |
| 加热与取餐 | 启动锅具，等火候进度；及时点下一步 | 忙碌班 8 秒、悠闲班 12 秒的取餐窗口；错过后烧焦重做当前热工序 |
| 交餐 | 点实体餐铃/出餐位 | 单次结算底价、剩余耐心小费、连续正确操作小费；顾客离队，下一单补位 |

每张票独立保存当前工序、耐心、加热与取餐窗口。悠闲班最多同时两票；忙碌班第三位顾客按班次在第 9、11 或 13 秒入队，最多三票。该票可能是急单，耐心更短但完成奖金更高；计时和奖励随存档恢复。误操作扣本单耐心并断连击；烧焦重做热工序、扣耐心并断连击；顾客超时离开失去该单收入。已入账收入不倒扣，不产生债务或死局。库存制作和过期不直接发钱。

当前数值：悠闲班四单、每单 88 秒；忙碌班七单、每单 56 秒。两档均不消耗体力，可持续开班。十菜基础价按四、五、六步复杂度大体分组递增，忙碌班价与小费倍率更高；真实玩家速度与收益仍需试玩调校。

## 本次生活与存档闭环

- 果茶售价 15 贝，可重复购买；海风马克杯 60 贝，限买一次，购买后在店前小桌出现摆件。
- 长椅休息使天数加一；进行中的班次先完成再休息。玩家可以闲逛或休息，不强制每日开工。
- `TalentParkSave` 只读写 `user://talent_park_mvp.json`：约每 10 秒和开班、交餐、购买、休息、退出等关键操作保存，F5 手动保存；主档损坏可从一份 `.bak` 读回。餐馆中途工序、现金、时钟、天数、位置和海风杯状态需能恢复。

## 城市跑单：取件、选路、妥投

| 环节 | 场景对象与玩家动作 | 状态与即时反馈 |
|---|---|---|
| 接单 | 驿站实体任务架挂可辨认的包裹牌；玩家接下悠闲单或多站冲刺单 | 包裹在货架上高亮，HUD 指示件数与剩余时间 |
| 核对取件 | 点击带同色封签的包裹，再点击自己的配送箱/车筐 | 包裹从架上移到箱内；错件可退回，需核对目的地 |
| 路上选择 | 玩家亲自穿过可通行街巷、斑马线、桥与交通节点，地图给方向和目的地轮廓 | 路线熟悉度、天气/人流改变耗时；捷径靠探索发现，不由选项题决定 |
| 交付 | 走到正确门牌/收件柜与目标交互，必要时将怕水件放入干燥柜 | 收件对象确认并留下签收反馈；交错门可取回修正 |
| 完成 | 最后一件妥投或主动结束 | 按时、完好和多站顺序决定报酬；解锁路线熟悉度与街区发现 |

状态为 `已接 → 已核对 → 已装载 → 在途 → 已妥投 → 已结算`。安全通行应始终是可行的高分路线；危险逆行不应成为最优解。悠闲单以一站和宽松期限供沿途探索；冲刺单以 2–3 站、并行期限和路线组合换更高收益。逾期保留基础收入、失去时效奖金；损坏要回驿站处理，不清空整班收益。期限由路线长度、移动方式、天气和交接动作估算，不能复用答题倒计时。

## 创意自由职业：采样、制作、交稿

| 环节 | 场景对象与玩家动作 | 状态与即时反馈 |
|---|---|---|
| 接委托 | 工作室墙面有图形简报/委托夹；可选散步采样或限时商业委托 | 客户需求固定为色调、主题、用途 2–3 个可见标签 |
| 城市采样 | 去真实街角、街市、渡口等，调整相机取景；在合适角度与距离按交互拍摄/速写 | 相册/素材夹新增原创图样或声音；同一地点不靠重复点击刷质量 |
| 制作 | 回工作台拿取纸张、颜料、形状/字体样片，点选画板槽位摆放与调整 | 作品模型/贴图在场景里实时变化；可撤回最近一步 |
| 校对 | 将实体样稿放到检查架，查看与客户标签的契合反馈 | 质量由主题覆盖、构图可读性及采样独特性组成，给出可改进原因 |
| 交稿 | 把样稿交到客户或店门牌展示架 | 获得报酬与作品署名；优秀作品可持续展示，扩展后续委托与装扮素材 |

状态为 `简报 → 素材采集中 → 排版中 → 待校对 → 可交稿 → 已展示`。需求不匹配可以返工；低质量交稿只减本次奖金，不封锁职业。悠闲委托可跨日完成并允许自由探索；限时商业委托需要更多深圳街区的独特素材、交期短，报酬应覆盖区内交通、工具消耗与额外时间。升级优先解锁新画板槽位、相机镜头、纸材/印刷与展示位置，使创造空间真实增加。

- 忙碌班完美总收入和单位时间收入潜力高于悠闲班；收入/分钟由实测检验。失误最多影响本单或当班奖金，不制造负债。
