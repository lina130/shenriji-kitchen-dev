# 深圳人才公园场景测绘与证据

## 用途与尺度

`CityTalentPark3D` 是深圳湾人才公园和邻近后海商圈的首版可玩骨架。坐标约定为 **1 Godot 单位 = 1 设计米**，`x` 向东、`z` 向南、地面基准 `y=0`。这只是按公开导览图比例重绘的设计平面，**没有经过 GIS 配准、实地测绘或建筑图纸复核**，因此不能称为真实地理坐标或严格 1:1 实测还原。

场景内公园设计边界为约 840×1000 设计米的外接矩形；公园真实轮廓并非矩形，故此乘积不是公园面积。湖体用约 281×340 米半轴的变形椭圆建模，理论面积约 30 万平方米，旨在与官方公布水体量级相符，并保留西岸、东岸、南北草坡的空间。园内详细岸线、坡高、建筑占地和步道宽度均须待权威测绘资料或现场采样校准。

## 依据与对应关系

1. [南山区政府：深圳人才公园](https://www.szns.gov.cn/mlns/stns/lc/csgy/content/post_12595660.html)，2026-01-12，正文记载后海位置、总面积 **77 万平方米**、水体 **30 万平方米**、内湖、山坡、草坪、院士林、百杰山、人才书吧及求贤阁。该页附 [官方访客导览图](https://www.szns.gov.cn/img/4/4403/4403269/12595660.jpg)。导览图为本场景的主要相对位置依据：北接海德三道、西邻登良路、东邻沙河西路、南到东滨路；求贤阁与人才书吧在西南岸，百杰山在东北岸，环湖路贯通，π桥与星光桥在南侧和东侧。导览图附图说明写水体约 **32 万平方米**，与页面正文 30 万平方米有差异；场景采用正文 30 万平方米作为量级目标。
2. [南山区政府：人才公园二期听证报告](https://www.szns.gov.cn/sz/tzgg/content/post_11446922.html) 也明确公园位于科苑南路以东、沙河西路以西、东滨路以北、海德三道以南，与深圳湾滨海休闲带相连。
3. [南山区政府：深圳湾体育中心](https://www.szns.gov.cn/mlns/whns/tycg/content/post_12589347.html) 将“春茧”置于后海中心区东北角；[深圳市地名志（下）](https://pnr.sz.gov.cn/attachment/1/1285/1285348/10537364.pdf) 记载中国华润大厦“春笋”在海德三道路南、科苑南路东，建筑高度 **392.5 米**。场景保留这个有文献高度的地标体量。
4. [南山区政府：后海商业文化区无人机航线](https://www.szns.gov.cn/bsfw/hlwzwfw/zwdt_140139/content/post_10830667.html) 提及人才公园—海岸城，并串联深圳湾万象城、保利广场、天利商务中心及中国华润大厦。场景将相关商业体置于园区西、北的周边城市层；深圳湾一号和普通金融高楼也仅作远景体量，具体红线、层数与建筑高度尚未测定。

## 场景坐标和集成接口

脚本：`res://scripts/city3d/city_talent_park.gd`，`class_name CityTalentPark3D`，可以单独 `new()` 并 `add_child()`。镜头由主场景创建，可自由旋转。本场景不绘制贴在地图上的文字。

| 名称 | 设计坐标（米） | 用途及精度 |
| --- | --- | --- |
| `SPAWN_POINT` | `(-320, 0.5, 150)` | 西岸游戏出生点；设计点位，非真实入口测量 |
| `RESTAURANT_ANCHOR` | `(-310, 0, 120)` | 餐馆玩法预留 30×30 米清空地块，18×18 米店面可放置，门朝 `+Z`；**游戏原创店址** |
| `BOOKBAR_ANCHOR` | `(-315, 0, 285)` | 西南岸求贤阁书吧的示意锚点，需实地校准 |
| `OVERVIEW_CENTER` | `(0, 0, -10)` | 镜头总览中心 |
| `OVERVIEW_SPAN` | `1700` | 可见园区和周边地标的建议正交相机跨度 |
| `PARK_BOUNDS` | `x[-420,420], z[-500,500]` | 园区首版设计外接框，非真实红线 |

`is_walkable_position(Vector3)` 只根据世界边界和水陆函数进行存档落点**初筛**；建筑碰撞与可站立高度仍须由主场景的物理射线确认。`ground_height_at(Vector3)` 返回坡地设计高度。湖水与南侧海面没有地板碰撞，非桥岸线生成防止普通步行入水的物理边界；两座桥有独立桥面碰撞。

## 尚未确认

- 官方导览图没有标注比例尺和各景观实体尺寸；当前湖岸形状、园路宽度、坡度与桥宽是设计假设。
- 导览图相对位置可靠到“哪一岸、哪一角”的层级；书吧、桥、雕塑、春笋、春茧及商圈楼群的精确坐标需 GIS 或现场测量校准。
- 春笋高度有文献依据，但其塔身直径、立面分格尚为简化造型；春茧、深圳湾一号、海岸城等高度和外轮廓尚未精模。
- 现有桥和书吧为可辨几何骨架；动画、动态水、材质贴图、生态细节与真实店招尚待制作。餐馆玩法地块是原创位置，不应归因于官方导览图。
