# 《深日记》0.2.0 旧城经营版

这一版不再用装备做推进，而是用旧货生意本身构成长线驱动力。

## 核心经济循环

1. 工作赚钱，保证房租和日常生活。
2. 在街区、废品站和旧址寻找旧物。
3. 每天市场会出现热门与冷门品类，出售价格随行情变化。
4. 可以选择立即出售，也可以把货物放在陈伯柜台寄卖，等待更合适的成交时机。
5. 完成寄卖会积累熟客口碑，口碑和累计成交额会带来更好的买家与新的旧址入口。
6. 赚钱后可以扩大摊位，增加寄卖容量和成交机会。
7. 更深旧址会带来更高价值、更加稀有的旧物，再回到市场中形成新的现金流。

## 旧址探索

- 旧楼地下室：免费开放的入门探索点。
- 废弃管道层：累计做出足够旧货生意后解锁。
- 封存车间：拥有固定摊位后解锁。
- 积水隧道：完成多次寄卖、形成熟客口碑后解锁。

探索中没有装备系统，也没有数值面板。手电光圈会随时间收缩，旧物收集、寄卖周转、摊位规模和熟客关系构成全部成长。

## 新增内容

- 旧货行情每日变化。
- 立即出售与寄卖两种资金策略。
- 寄卖柜、摊位升级与熟客口碑。
- 四个可重复进入的旧址探索点。
- 22 种城市旧物和四级稀有度。
- 雾中光照探索与自动返回地面。
- 经济进度存档和读档。
