# 《深城日常》0.3.1 经营交互修复版

本版集中解决实际试玩中发现的五类问题。

## 1. 界面遮挡与鼠标失效

- 所有长界面放入独立滚动区域。
- 关闭按钮固定保留，不再被经营内容顶出屏幕。
- 出餐工位、菜单、银行和批发按钮不再周期性销毁重建。
- 鼠标按下期间按钮保持稳定，真实窗口测试会检查按钮实例未被替换。

## 2. 空气墙修复

- 删除没有视觉对应的内部碰撞。
- 床、冰箱、书桌、货架、摊位、机器和旧址障碍按绘制位置重新对齐。
- 公园池塘改用连续圆形碰撞，不再使用覆盖大片空地的矩形墙。
- 便利店和旧货市场打开中央过道，避免实体货架堵死路线。

## 3. 招人效果

- 招临时帮手会立即增加 3 点劳力库存。
- 同一天还会真实增加 3 点劳力上限，最多增加 6 点。
- 第二天临时劳力加成自动重置。
- 经营界面显示“当前劳力/上限”和“当前脑力/上限”。

## 4. 银行与彩票实体

- 城中村街道新增实体银行与彩票站入口。
- 银行大厅内有独立银行柜台和彩票柜台。
- 银行柜台可办理存款、取款和查询利息。
- 彩票柜台可购买单张或十张彩票。
- `B` 快捷键仍保留为便捷入口。

## 5. 熟客关系效果

- 点头之交：见面更热情，偶尔会送一点吃的。
- 熟人：批发进货获得折扣，餐馆客人的耐心增加。
- 老朋友：旧货行情获得额外增益，并获得对应稀有旧物。
- 对话框会直接说明当前关系带来的实际效果。
- 旧货行经营界面显示当前熟客网络带来的帮助。

## 验证

- 真实窗口玩家操作 Playtest：49 步全部通过。
- 完整经营与收集模拟：集齐 24 件旧物，总资产超过 5 万。
- 100 次随机 30 日经济压力测试通过。
- Windows 独立导出及运行检查通过。
