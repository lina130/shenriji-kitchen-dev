# 已知问题与版本边界

## 当前明确边界

- 正式商业级像素美术尚未完成；当前主要使用程序化或 Beta 基线资源，逐帧换装动画、角色细节、场景装饰和统一视觉规范仍待正式替换。
- 正式音频尚未完成；当前主要使用可复现占位音频和部分环境音，混音、循环、音效数量与专业响度标准仍待制作。
- 地图仍会继续扩展；当前大城区、室内分区和区域入口已经可用，但后续还会补充更多场景、道路连接、地点密度和室内切换细节。
- Steamworks SDK 尚未接入真实 App ID、Depot ID、云存档和成就上线流程；现有平台接口只做能力检测和本地回退。
- 公网多人联机尚未接入；当前只有本地或局域网 ENet 合作接口、逻辑快照和远程请求，大房间、弱网恢复和公网服务器仍待验证。
- Windows 版本尚未代码签名，首次运行可能触发 SmartScreen 提示。
- 部分区域仍可能出现场景密度偏高、物体摆放拥挤、UI 细节不统一或交互提示不够明显的问题；这些属于 0.5.0 后的持续打磨范围。
- 节日和生日使用游戏内固定月历日期，尚未接入完整农历换算。
- 模组创意工坊和高级发行工具仍处于粗糙阶段，优先保证游戏本体可玩。

## 已知风险

- 早市、午市、晚市切换会清空未完成半成品；这是设计规则，不代表存档丢失。
- 自动存档按游戏内绝对时间判断，每约 15 游戏分钟触发，关键节点会立即保存；磁盘写入失败时保留原档并提示。
- 新存档带版本和校验和，支持 v1 至 v15 逐级迁移；主档损坏时会尝试备份，读档失败后不会覆盖原档，但大规模旧档迁移仍建议先保留备份。
- 收购箱按当前规则不可取回；误放高价值物品时，只能在结算前通过备份恢复。
- 格子背包与总案中近乎无限背包的表述存在版本取向差异；当前优先星露谷式格位管理。
- 多工序流水线、员工事件、节日活动和首周经济参数仍需要更多真人节奏测试调平。

## 发布判断

当前构建已经可玩，具备连续大城区与室内切换、早餐店点击流水线、首周经济闭环、多工序经营、事件解锁门控、背包储存、NPC 与节日系统，并支持旧档迁移。

正式商业发行前仍需完成正式美术、正式音频、Steamworks 凭证、公网联机、Windows 签名和最终 build_release.ps1 验证。本文档不声明尚未复跑的全量测试通过。

## 首版交付已知测试问题

- 连续大城区已经通过 `--playtest --spot-city` 58 步和 `--scene-check`。旧的 145 步全流程 `--playtest` 仍引用已下线的 `go_commercial`、`go_industrial`、`go_suburb` 传送门和老区域名，运行到第 44 步后会因旧导航脚本失败；需要把该脚本改写成连续城区路线。
- 这不影响当前 Windows 导出包启动和已有核心玩法，但代表“全量 145 步真实窗口回归”尚未完成。发下一版前必须补齐。
