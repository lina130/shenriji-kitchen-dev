# 已知问题与版本边界

## 当前版本明确不含

- 正式像素美术、角色逐帧动画和商业级音轨。
- 完整 NPC 行程、恋爱、家庭和多区域旅游。
- 自由装修、复杂供应链和城市级经济模拟。
- 轻量联机合作、Steam 成就与云存档。

## 已知风险

- 当前对话与订单文本为短循环内容，长期游玩会重复。
- NPC 使用简单巡逻，不会严格避障或按真实作息出入场景。
- 旧址与店铺场景使用程序化占位绘制，尚不是正式 TileMap 美术层。
- 完整经营模拟可稳定达标，但真人节奏、手感和视觉反馈仍需公开测试。
- Windows 版本尚未进行代码签名，首次运行可能出现 SmartScreen 提示。

## 发布判断

`0.3.0` 已形成可循环、可放大的核心经营闭环：库存投入、实时出餐、订单压力、批发差价、银行利息、彩票、店铺扩张、旧址收益和稀有物收集均已落入系统。当前适合公开 Demo 与好友测试，完整商业版仍需补足美术、内容量和长期平衡。
