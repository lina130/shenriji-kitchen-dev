# 已知问题与版本边界

## 当前版本明确不含

- 正式像素美术、角色逐帧动画和商业级音轨。
- 完整 NPC 行程、恋爱、家庭、学业考试和多区域旅游。
- 自由装修、复杂供应链和城市级经济模拟。
- 轻量联机合作、Steam 成就与云存档。

## 已知风险

- 当前对话为短循环文本，长期游玩会重复。
- NPC 使用简单巡逻，不会严格避障或按真实作息出入场景。
- 旧址布局为程序化占位绘制，尚不是正式 TileMap 美术层。
- 长时间探索、数十件寄卖订单和跨月存档仍需更多真人测试。
- Windows 版本尚未进行代码签名，首次运行可能出现 SmartScreen 提示。

## 发布判断

`0.2.0` 已具备完整的“探索—估值—出售/寄卖—扩摊—解锁”重复循环，适合公开 Demo、好友测试和玩法验证；正式商业版仍需补足美术、内容量与长期平衡。
