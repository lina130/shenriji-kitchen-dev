# 已知问题与版本边界

## 当前版本明确不含

- 正式像素美术、角色逐帧动画和商业级音轨。
- 完整 NPC 行程、恋爱、家庭和多区域旅游。
- 自由装修、复杂供应链和城市级经济模拟。
- 轻量联机合作、Steam 成就与云存档。

## 已知风险

- 当前对话与订单文本为短循环内容，长期游玩会重复。
- 节日目前以加成与提示为主，尚未加入专属场景布置和限定商品。
- 四季表现是色调与点缀，尚未替换整套季节美术。
- NPC 使用简单巡逻，不会严格避障或按真实作息出入场景。
- 旧址与店铺场景使用程序化占位绘制，尚不是正式 TileMap 美术层。
- Windows 版本尚未进行代码签名，首次运行可能出现 SmartScreen 提示。

## 发布判断

`0.4.0` 已把经营搬进真实场景，并把时间、日历、节日、季节与彩蛋式摸金接入主循环。经营闭环可稳定达标：库存投入、实时出餐、批发差价、银行利息、彩票、店铺扩张、旧址收益和稀有物收集都能循环。当前适合公开 Demo 与好友测试，完整商业版仍需补足美术、内容量和长期平衡。
