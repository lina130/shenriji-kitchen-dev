## 1. 决策（逐条裁决，无歧义）

| # | 争议点 | 最终裁决 | 依据 |
|---|---|---|---|
| D1 | 开局宠物窝 | **开局绝对不预置**。`pet_bed` 是 `items.csv` 中的 `decor`，需玩家**购买后使用**才在出租屋出现 | 任务硬约束 |
| D2 | 解锁路径 | **四条并行，任一可触发**：① NPC 阿灰引荐 ② 救助事件 ③ 宠物店直接领养 ④ 节日/季节限定 | 任务要求"逐步出现" |
| D3 | 领养入口 | **场景实物**：宠物店内的"领养登记台"（`WorldInteractable`），TAP 打开领养候选（**不是菜单，是场景内卡片**） | 无下拉菜单约束 |
| D4 | 领养前置 | **必须先有 `pet_bed`**。无窝时阿灰会说"先给它准备个睡觉的地方吧"，领养台不可交互 | 自然解锁 |
| D5 | 喂养/清洁 | **实物驱动**：`pet_feed` / `pet_medicine` 从背包消耗；洗澡需在**宠物店洗澡台**或**家有浴缸时在家** | 拒绝纯菜单 |
| D6 | 陪伴 | **场景内 TAP 宠物实体**触发 `play()`，消耗体力与玩具 | 动作驱动 |
| D7 | 技能 | **不设技能树**。宠物 `bonus_type` 通过**日常陪伴自然生效**（如 `patience` 让顾客耐心+25%），无面板显示 | 无数值属性条 |
| D8 | 经济开销 | **固定物价**：领养价见 `pets.csv`，粮 10/袋，玩具 18，营养膏 26，洗澡 8，训练 25 | 固定物价约束 |
| D9 | 家庭互动 | **同住 NPC 反应**：梅姨/李妈看到宠物会说不同台词；宠物会出现在出租屋场景 | 家庭互动 |
| D10 | 存档迁移 | **新增 `pet_unlock_flags` 字段**，旧档默认空字典，不破坏兼容 | 存档兼容 |
| D11 | 隐藏解锁 | **救助事件**：雨天/夜晚在特定场景遇到受伤小动物，选择救助 → 解锁领养资格 | 隐藏解锁 |
| D12 | 节日联动 | **季节限定宠物**：夏季河畔出现"老曲的乌龟"，节日期间宠物店打折 | 节日联动 |
| D13 | 提示分离 | NPC 台词走 `NoticeManager.show_npc_message`，系统提示走 `show_message`，场景提示走 `show_scene_message` | 提示分离约束 |
| D14 | 宠物窝位置 | **出租屋场景固定锚点**，购买后 `pet_bed` 实体出现在锚点，宠物休息时走到窝边 | 场景点击经营 |

## 4. 解锁流程（四条路径）

### 路径 A：NPC 引荐（主路径）

1. 玩家首次进入 `petshop` 场景 → 阿灰实体可见
2. TAP 阿灰 → `RelationshipManager.talk_to("ahui")` → 阿灰说："店里最近来了几只小家伙，你要是想养，先给它们准备个睡觉的地方。"
3. 写入 flag `ahui_met`
4. 玩家购买 `pet_bed` 并使用 → 出租屋出现宠物窝
5. 再次进入 `petshop` → 领养台可交互
6. TAP 领养台 → 显示 `pet_unlock.csv` 中 `unlock_type=shop` 且 `required_flag=ahui_met` 的宠物卡片
7. TAP 卡片 → `PetManager.adopt(pet_id)` → 扣钱 → 宠物出现在出租屋

### 路径 B：救助事件（隐藏解锁）

1. 雨天/夜晚玩家在 `street` 场景 → `rescue_spot` 纸箱可见
2. TAP 纸箱 → 场景提示："雨里有个纸箱，里面传来细细的叫声。"
3. 选择"打开看看" → 发现受伤的小狗 → 选择"带回家" → 写入 flag `rescue_dog_seen`
4. **前置**：必须有 `pet_bed`，否则提示"先给它准备个睡觉的地方吧"
5. 带回家后 → `PetManager.adopt("dog_xiaohei")` **免费**（救助不收费）
6. 小狗初始状态：`fullness=30, energy=40, mood=50, clean=20`（需要照顾）

### 路径 C：宠物店直接领养

1. 玩家直接进入 `petshop`（无需先见阿灰）
2. 领养台可交互，但**只显示 `required_flag` 为空的宠物**（如 `rabbit_mochi` 需 `ahui_met`，不显示）
3. TAP 卡片 → 正常领养流程

### 路径 D：季节/节日限定

1. **夏季**：玩家在 `riverside` 遇到老曲 → 对话 → 老曲提出送石龟 → 写入 flag `turtle_offered`
2. **节日**：节日期间 `petshop` 出现鹦鹉 → 领养价打折（固定折扣，如 8 折）
3. **裁决**：季节/节日宠物**不强制领养**，错过不补，符合"自然出现"。

## 5. UI 与提示

### 5.1 领养候选卡片（场景内，非菜单）

- **形式**：场景内浮动的卡片，显示宠物头像 + 名字 + 一句话描述 + 领养价
- **交互**：TAP 卡片 → 确认领养；SECONDARY → 关闭
- **裁决**：**不使用 `PopupMenu` / `OptionButton`**，用 `Control` 节点 + `TextureButton` 实现

### 5.2 宠物状态显示（无数值条）

- **形式**：宠物实体头顶的**表情气泡**（开心/饿/累/脏）
- **裁决**：**不显示数字**，只显示表情。玩家通过表情判断需求。
- **表情映射**：
  - `fullness < 30` → 饿的表情
  - `energy < 30` → 累的表情
  - `clean < 30` → 脏的表情
  - `mood > 70` → 开心的表情
  - 其他 → 平静的表情

### 5.3 提示分离

| 场景 | 通道 | 示例 |
|---|---|---|
| 阿灰说话 | `NoticeManager.show_npc_message` | "先给它准备个睡觉的地方吧。" |
| 系统提示 | `NoticeManager.show_message` | "橘猫阿黄吃饱了，蹭了蹭你的手。" |
| 场景提示 | `NoticeManager.show_scene_message` | "雨里有个纸箱，里面传来细细的叫声。" |

```gdscript
func to_save() -> Dictionary:
    return {
        "adopted": adopted,
        "active_pet_id": active_pet_id,
        "unlock_flags": unlock_flags,
        "rescue_seen": rescue_seen,
    }

func from_save(data: Dictionary) -> void:
    adopted = data.get("adopted", {})
    active_pet_id = data.get("active_pet_id", "")
    unlock_flags = data.get("unlock_flags", {})
    rescue_seen = data.get("rescue_seen", {})
    # 旧档无宠物字段时，全部为空，不报错
    changed.emit()
```

### 7.3 迁移函数

```gdscript
func migrate_from_v14(data: Dictionary) -> Dictionary:
    # v14 无宠物系统，补空字段
    if not data.has("pet_data"):
        data["pet_data"] = {
            "adopted": {},
            "active_pet_id": "",
            "unlock_flags": {},
            "rescue_seen": {},
        }
    return data
```

**裁决**：迁移函数注册到 `SaveManager` 的迁移链，**版本号以 G0.4 结果为准**。

## 独立方案

# 宠物系统：自然解锁 × 经济联动 —— 独立可执行方案

> **独立立场声明**：本方案**不采用**"宠物系统 = 一个 `PetManager` + 一个宠物界面"的主流做法。理由：现有 `pet_manager.gd` 已经把宠物做成了一个**数值面板**（fullness/energy/mood/clean/training/growth 六条隐藏条），这与硬约束"无数值属性条"直接冲突，也与"避免任务面板"的意图冲突。本方案把宠物**降维成场景实体 + 状态机 + 事件流**，数值只作为内部驱动，永不暴露为 UI 条。

## 0. 与现有代码的冲突裁决（先拍板）

## 1. 核心架构：宠物是"场景实体"，不是"系统面板"

```
┌─────────────────────────────────────────────────┐
│  Layer 3  事件流（EventBus）                     │
│  rescue_triggered / adoption_slip_granted /      │
│  pet_arrived / pet_sick / pet_grew_up            │
├─────────────────────────────────────────────────┤
│  Layer 2  PetRuntime（每只宠物一个实例）          │
│  - 状态机：absent → waiting → home → adult       │
│  - 档位派生：_derive_stage(state) -> String      │
│  - 无 UI，只 emit signal                         │
├─────────────────────────────────────────────────┤
│  Layer 1  场景实体（PetEntity extends WorldInteractable）│
│  - 挂在 home / pet_shop / riverside 场景         │
│  - on_tap → PetRuntime.interact(action)          │
│  - 贴图随档位切换（脏/饿/困 → 不同 sprite）       │
├─────────────────────────────────────────────────┤
│  Layer 0  数据（CSV，唯一事实源）                 │
│  pets.csv / pet_care.csv / pet_unlock.csv        │
└─────────────────────────────────────────────────┘
```

**关键决策**：`PetManager` 从 autoload 降级为**纯数据容器 + 事件转发**，不再持有 UI 逻辑。所有交互由场景实体发起。

## 2. 自然解锁链（四阶段，无任务面板）

### 2.1 阶段表（`data/pet_unlock.csv`）

| stage_id | 触发条件（`condition` 列） | 场景表现 | 玩家可做 |
|---|---|---|---|
| `s0_absent` | 开局默认 | 家里**无宠物窝**，无任何宠物相关实体 | 无 |
| `s1_noticed` | `talked_to:ahui >= 1` 或 `visited:pet_shop >= 1` | 宠物店门口出现 `ahui`，橱窗里有猫；**家里仍无窝** | 只能看、只能聊 |
| `s2_rescue` | `day >= 3` 且 `weather == rain` 且 `visited:riverside >= 1` | 河边出现**纸箱 + 湿透的小猫**（`PetEntity` 临时实体） | TAP 纸箱 → 触发救助事件 |
| `s3_slip` | `s2_rescue` 完成 | `ahui` 给 `adoption_slip`（领养凭证，进背包） | 可凭凭证领养**1 只** |
| `s4_home` | 领养完成 | 家里**自动出现宠物窝**（`PetEntity` 在 home 场景实例化） | 喂/玩/洗/睡 |
| `s5_more` | `days_together >= 6` 且 `ahui_affinity >= 10` | 宠物店解锁第二只领养位 | 可领养第 2 只 |

**硬约束落地**：
- `s0_absent` 时 `home` 场景**不实例化任何 PetEntity**，`scene_layout.csv` 里 `home` 的 `pet_bed` 条目 `unlock_stage = s4_home`。
- 领养凭证 `adoption_slip` 是**道具**，不是任务标记。玩家在背包里看到它，点一下 → 弹出"去宠物店"的场景提示（`NoticeManager.show_scene_message`）。

### 2.2 救助事件（`s2_rescue`）的具体实现

```gdscript
# scripts/pet/rescue_event.gd
# 挂在 riverside 场景的纸箱实体上
extends WorldInteractable

func on_tap() -> void:
    if not PetUnlockManager.can_trigger("s2_rescue"):
        NoticeManager.show_scene_message("纸箱里空空的，只有几片落叶。", "河边")
        return
    # 触发救助：不弹窗，直接播放动画 + 台词
    PetUnlockManager.trigger_rescue("cat_huang")
    NoticeManager.show_npc_message(
        "哎，这么小就淋成这样……你要是不嫌弃，先抱回去？",
        "阿灰", "positive"
    )
    # 纸箱实体消失，改为"湿猫"实体
    queue_free()
```

**无任务面板**：玩家不会看到"任务：救助小猫"。他们只看到河边有个纸箱，点一下，阿灰说话，猫被抱走。**下一步去哪，靠阿灰的台词暗示**（"宠物店有干毛巾"）。

## 3. 领养：凭证制，不是购买制

### 3.1 领养流程

```
玩家背包有 adoption_slip
  → 走到宠物店，TAP 阿灰
  → 阿灰说："凭证带了吗？挑一只吧。"
  → 场景内出现 3 只候选宠物（PetEntity，可 TAP）
  → TAP 某只 → 确认（HOLD 1.5s，无弹窗）
  → 消耗 adoption_slip，宠物进 adopted
  → 阿灰说："它跟你了。家里我让人送个窝过去。"
  → home 场景下次加载时出现 pet_bed
```

### 3.2 为什么不用 `GameState.spend(price)`

现有 `adopt()` 直接扣钱，会让玩家觉得"宠物是商品"。改为凭证制后：
- **钱仍然花**：`adoption_slip` 本身要花钱（`pet_care.csv` 里 `slip_price = 80`），但花在**救助站/宠物店**，不是花在"买猫"。
- **价格固定**：`slip_price` 是固定物价，符合硬约束。
- **情感路径**：玩家先遇到猫（s2），再被给凭证（s3），再领养（s4）。三步走，每步都有 NPC 台词。

## 4. 喂养 / 清洁 / 陪伴：场景内点击，无界面

### 4.1 交互映射（`data/pet_care.csv`）

| action_id | 手势 | 前置 | 消耗 | 效果（档位） | 台词来源 |
|---|---|---|---|---|---|
| `feed` | TAP 宠物 | 背包有 `pet_feed` | `pet_feed ×1` | `hungry → ok` | 宠物动作 + 短句 |
| `play` | HOLD 宠物 | `energy >= tired` | 玩家体力 -3 | `sad → ok`，`training +4` | 宠物动作 |
| `bathe` | TAP 水盆 | 背包有 `pet_soap` | `pet_soap ×1`，钱 -8 | `dirty → clean` | 宠物甩水动画 |
| `rest` | TAP 宠物窝 | 无 | 无 | `tired → rested` | 宠物打呼 |
| `medicine` | TAP 宠物 | 背包有 `pet_medicine` | `pet_medicine ×1` | `sick → ok` | 阿灰远程台词 |

**关键**：`feed` 不是"打开宠物界面点喂食"，而是**走到宠物旁边，TAP 它**。宠物会做出"凑过来吃"的动作，`NoticeManager` 只显示一句短句（"阿黄吃得很香。"），**不显示任何数值**。

### 4.2 档位派生（`PetRuntime._derive_stage`）

```gdscript
func _derive_stage(state: Dictionary) -> Dictionary:
    # 内部 float → 对外档位字符串
    return {
        "hunger": _tier(state.fullness, 30.0, 70.0, "hungry", "ok", "full"),
        "energy": _tier(state.energy, 20.0, 60.0, "tired", "ok", "rested"),
        "clean":  _tier(state.clean,  30.0, 70.0, "dirty", "ok", "clean"),
        "mood":   _tier(state.mood,   30.0, 70.0, "sad", "ok", "happy"),
    }

func _tier(v: float, lo: float, hi: float, a: String, b: String, c: String) -> String:
    if v < lo: return a
    if v < hi: return b
    return c
```

**档位只用于**：
1. 宠物贴图切换（`dirty` → 脏兮兮的 sprite）
2. NPC 台词触发（`ahui` 看到 `dirty` 宠物会说"该洗澡了"）
3. 场景提示（`home` 场景进入时，若 `hungry` → `NoticeManager.show_scene_message("阿黄在碗边转圈。", "家里")`）

**永不用于**：UI 条、百分比、数字。

## 6. 经济开销：固定物价，但"开销"是隐性的

### 6.1 开销表（`data/pet_care.csv`）

| 项目 | 价格 | 频率 | 说明 |
|---|---|---|---|
| `adoption_slip` | 80 | 一次性 | 领养凭证 |
| `pet_feed` | 10 | 消耗品 | 一袋吃 3 天 |
| `pet_soap` | 8 | 消耗品 | 洗一次 |
| `pet_medicine` | 26 | 消耗品 | 生病时 |
| `pet_toy` | 18 | 耐用品 | 玩 5 次 |
| `vet_visit` | 60 | 事件 | 宠物生病时 |

**固定物价**：全部写死在 CSV，不随季节/节日浮动。

### 6.2 经济联动（关键设计）

宠物**不是纯开销**，它通过增益**回本**：

```
养猫（橘猫阿黄）：
  月开销：feed 10×10 + soap 8×4 + toy 18×1 = 150
  月收益：早餐店耐心 +25% → 每天多接 2 单 × 15 元 × 30 = 900
  净收益：+750
```

**但玩家不会看到这个计算**。他们只会感觉"养了猫之后，早餐店好像顺了一点"。

**经济压力**：若玩家**不喂**，宠物会：
- `hungry` → 宠物在场景里**叫**（`NoticeManager.show_scene_message("阿黄一直在叫。", "家里")`）
- `hungry` 持续 3 天 → `sick` → 需要 `vet_visit` 60 元
- `sick` 持续 2 天 → 宠物**离家出走**（`adopted` 移除，但保留 `adoption_slip` 可再领养）

**温柔治愈**：离家出走的台词是"阿黄在门口坐了很久，最后还是走了。它可能去找更适合的地方了。"——不惩罚，不指责。

```gdscript
func _migrate_v14_to_v15(data: Dictionary) -> Dictionary:
    # v14 无 pets 字段 → 视为未领养
    if not data.has("pets"):
        data["pets"] = {
            "adopted": {},
            "active_pet_id": "",
            "unlock_stage": "s0_absent",
            "rescue_done": false,
            "slip_used": false,
        }
    # 旧档若已有 adopted（理论上不会有），补新字段
    for pet_id in data["pets"].get("adopted", {}):
        var p: Dictionary = data["pets"]["adopted"][pet_id]
        p["learned_trick"] = p.get("learned_trick", false)
        p["sick_days"] = p.get("sick_days", 0)
    return data
```

### 4.2 `PetManager` 改造

**新增函数**：

```gdscript
# 领养（统一入口）
func adopt(pet_id: String, source: String = "shop") -> bool:
    if not can_adopt(pet_id):
        return false
    if source == "shop":
        if not slip_used and not InventoryManager.has("adoption_slip"):
            return false
        InventoryManager.remove_item("adoption_slip", 1)
        slip_used = true
    # source == "rescue" 时免费
    adopted[pet_id] = _default_state(pet_id)
    active_pet_id = pet_id
    unlock_stage = "s4_home"
    changed.emit()
    pet_adopted.emit(pet_id)
    return true

# 业务层可领养判定（批判 A2）
func can_adopt(pet_id: String) -> bool:
    if adopted.has(pet_id):
        return false
    if unlock_stage == "s0_absent":
        return false
    var row := ConfigDB.get_row("pet_unlock", "pet_id", pet_id)
    if row.is_empty():
        return false
    if row.required_flag != "" and not unlock_flags.get(row.required_flag, false):
        return false
    return true

# 档位派生（新增只读接口，批判 B1）
func get_stage(pet_id: String, key: String) -> String:
    if not adopted.has(pet_id):
        return ""
    var v := float(adopted[pet_id].get(key, 0.0))
    match key:
        "fullness": return _tier(v, 30.0, 70.0, "hungry", "ok", "full")
        "energy":   return _tier(v, 20.0, 60.0, "tired", "ok", "rested")
        "clean":    return _tier(v, 30.0, 70.0, "dirty", "ok", "clean")
        "mood":     return _tier(v, 30.0, 70.0, "sad", "ok", "happy")
    return ""

func _tier(v: float, lo: float, hi: float, a: String, b: String, c: String) -> String:
    if v < lo: return a
    if v < hi: return b
    return c

# 成长检查（批判 A4）
func _check_growth(pet_id: String) -> void:
    var days := int(adopted[pet_id].get("days_together", 0))
    var row := ConfigDB.get_row("pet_growth", "stage", "adult")
    if days >= int(row.min_days):
        adopted[pet_id]["stage"] = "adult"

# 离家出走（批判 C1）
func _pet_leaves(pet_id: String) -> void:
    adopted.erase(pet_id)
    if active_pet_id == pet_id:
        active_pet_id = ""
    slip_used = false  # 可再领养
    changed.emit()
    pet_left.emit(pet_id)
```

### 4.3 `PetUnlockManager` 新建

```gdscript
# autoload/pet_unlock_manager.gd
extends Node

func can_trigger(unlock_id: String) -> bool:
    var row := ConfigDB.get_row("pet_unlock", "unlock_id", unlock_id)
    if row.is_empty():
        return false
    # 场景检查
    if row.trigger_scene != "" and GameState.current_scene != row.trigger_scene:
        return false
    # 天气/时间/季节/节日检查
    if row.is_rain and not WeatherManager.is_raining():
        return false
    if row.is_night and not CalendarManager.is_night():
        return false
    if row.season != "" and CalendarManager.get_season() != row.season:
        return false
    if row.festival_id != "" and not FestivalManager.is_active(row.festival_id):
        return false
    # 天数检查
    if row.min_day > 0 and CalendarManager.get_day() < row.min_day:
        return false
    # 前置 flag
    if row.required_flag != "" and not PetManager.unlock_flags.get(row.required_flag, false):
        return false
    return true

func trigger(unlock_id: String) -> void:
    var row := ConfigDB.get_row("pet_unlock", "unlock_id", unlock_id)
    if row.unlock_flag != "":
        PetManager.unlock_flags[row.unlock_flag] = true
    PetManager.changed.emit()
```

**裁决**：`WeatherManager` / `CalendarManager` / `FestivalManager` 若不存在 → 对应检查**降级为 `true`**（不阻塞），并在 `docs/PET_FACTS.md` 记录。

```gdscript
# scripts/pet/pet_entity.gd
extends WorldInteractable

var pet_id: String = ""

func _ready() -> void:
    add_to_group("pet_entity")

    var clean := PetManager.get_stage(pet_id, "clean")

func on_hold() -> void:
    PetManager.play(pet_id)
```

## 第六部分：解锁流程（四条路径）

### 路径 A：NPC 引荐（主路径）

1. 首次进入 `petshop` → 阿灰实体可见
2. TAP 阿灰 → `RelationshipManager.talk_to("ahui")` → **`PetUnlockManager` 监听 `RelationshipManager.talked` 信号**，写入 `unlock_flags["ahui_met"] = true`（批判 B P0-6）
3. 领养台可交互 → 显示 `unlock_type=shop` 且 `required_flag` 满足的宠物卡片
4. TAP 卡片 → 检查 `adoption_slip` → `PetManager.adopt(pet_id, "shop")`
5. 领养完成 → `home` 场景下次加载时出现 `pet_bed` 实体 + `PetEntity`

### 路径 B：救助事件（隐藏解锁）

1. `day >= 3` + 雨天 + 玩家在 `riverside` → `rescue_spot` 可见
2. TAP 纸箱 → 场景提示 + 两个选择按钮
3. 选"打开看看" → 发现受伤小狗 → 选"带回家" → 写入 `unlock_flags["rescue_dog_seen"] = true`
4. **前置**：`unlock_stage >= s1_noticed`（已见过阿灰），否则提示"先找阿灰问问"
5. `PetManager.adopt("dog_xiaohei", "rescue")` → **免费**
6. 小狗初始状态：`fullness=30, energy=40, mood=50, clean=20`

### 路径 C：宠物店直接领养

1. 玩家直接进入 `petshop`
2. 领养台可交互，但**只显示 `required_flag` 为空的宠物**（`rabbit_mochi` 需 `ahui_met`，不显示）
3. **仍需 `adoption_slip`**（X1 裁决：shop 路径统一凭证制）
4. TAP 卡片 → 正常领养

### 路径 D：季节/节日限定

1. **夏季**：`riverside` 遇到老曲 → 对话 → 写入 `unlock_flags["turtle_offered"]`
2. **节日**：节日期间 `petshop` 出现鹦鹉 → 领养价打折（固定 8 折）
3. **裁决**：季节/节日宠物**不强制领养**，错过不补
