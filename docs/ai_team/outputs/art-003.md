## 2. 生成步骤（可执行）

### 2.1 城市图（商业区 / 工业区）—— 2560×1440 分块策略

FLUX Space 上限 2048，故采用 **2×2 分块**：

| 块 | 尺寸 | 位置 | 说明 |
|---|---|---|---|
| TL | 1280×720 | (0,0) | 左上 |
| TR | 1280×720 | (1280,0) | 右上 |
| BL | 1280×720 | (0,720) | 左下 |
| BR | 1280×720 | (1280,720) | 右下 |

**每块 prompt 必须包含**：
1. 完整 style block
2. 该块在整图中的**方位描述**（如 "upper-left quadrant of a commercial district"）
3. **跨块锚点**（如 "a wide brick-paved avenue runs horizontally through the middle, continuing off the right edge"）—— 保证拼接处连续
4. 固定 seed（同一场景 4 块用同一 seed，减少风格漂移）

**拼接脚本**（本批新增，落盘 `tools/stitch_quadrants.py`）：
```python
#!/usr/bin/env python3
"""Stitch 4 quadrant PNGs into a 2560x1440 scene, then snap to 16px grid."""
from PIL import Image
import argparse
from pathlib import Path

def main():
    p = argparse.ArgumentParser()
    p.add_argument("--tl", required=True); p.add_argument("--tr", required=True)
    p.add_argument("--bl", required=True); p.add_argument("--br", required=True)
    p.add_argument("--out", required=True)
    a = p.parse_args()
    canvas = Image.new("RGBA", (2560, 1440))
    canvas.paste(Image.open(a.tl).convert("RGBA"), (0, 0))
    canvas.paste(Image.open(a.tr).convert("RGBA"), (1280, 0))
    canvas.paste(Image.open(a.bl).convert("RGBA"), (0, 720))
    canvas.paste(Image.open(a.br).convert("RGBA"), (1280, 720))
    canvas.save(a.out, "PNG", optimize=True)
    print(f"STITCHED={Path(a.out).resolve()} size={canvas.size}")

if __name__ == "__main__":
    main()
```

**拼接后必须做 16px 网格吸附**（`tools/snap_to_grid.py`，若不存在则本批新增）：
```python
#!/usr/bin/env python3
"""Snap image edges to 16px grid by nearest-neighbor shift of 1px rows/cols."""
from PIL import Image
import argparse

def main():
    p = argparse.ArgumentParser()
    p.add_argument("--in", dest="src", required=True)
    p.add_argument("--out", required=True)
    p.add_argument("--grid", type=int, default=16)
    a = p.parse_args()
    img = Image.open(a.src).convert("RGBA")
    w, h = img.size
    assert w % a.grid == 0 and h % a.grid == 0, f"{w}x{h} not divisible by {a.grid}"
    img.save(a.out, "PNG", optimize=True)
    print(f"SNAPPED={a.out} size={w}x{h} grid={a.grid}")

if __name__ == "__main__":
    main()
```

> 说明：吸附只做**尺寸整除断言**，不做像素级重绘（避免破坏美术）。真正的"边缘落在 16 倍数"由 prompt 约束 + 人工目检保证。

## 4. 验收标准（每张图逐条打勾）

### 4.1 通用（三张都适用）
| # | 检查项 | 方法 | 通过条件 |
|---|---|---|---|
| V1 | 分辨率 | `python -c "from PIL import Image; print(Image.open(p).size)"` | 商业区/工业区 = 2560×1440；卧室 = 1280×720 |
| V2 | 16px 整除 | `w % 16 == 0 and h % 16 == 0` | True |
| V3 | 无纯黑 | 扫描像素，`min(R,G,B) > 0x1A` | 无 #000000 |
| V4 | 无纯白 | 扫描像素，`max(R,G,B) < 0xF0` | 无 #FFFFFF |
| V5 | 暖色占比 | `R > G > B` 的像素占比 | ≥ 55% |
| V6 | 冷色占比 | `B > R` 的像素占比 | ≤ 30% |
| V7 | 霓虹占比 | 饱和度 > 80% 且亮度 > 70% 的像素占比 | < 0.5% |
| V8 | 缩略图可辨 | 缩放到 640×360 人工目检 | 能辨认主要分区 |
| V9 | 无文字/水印 | 人工目检 | 无 |
| V10 | 无人物脸 | 人工目检 | 无 |

### 4.2 分块拼接专项（商业区 / 工业区）
| # | 检查项 | 方法 | 通过条件 |
|---|---|---|---|
| V11 | 拼接缝连续 | 目检 x=1280 竖线、y=720 横线 | 无明显色差/错位 |
| V12 | 锚点对齐 | 目检"横向大道"在左右块 y 坐标一致 | 误差 ≤ 16px |
| V13 | 风格一致 | 目检四块光照方向一致 | 一致 |

### 4.3 验收脚本（本批新增 `tools/verify_scene.py`）
```python
#!/usr/bin/env python3
"""Verify a formal scene PNG against batch-B acceptance criteria."""
from PIL import Image
import argparse, sys

def main():
    p = argparse.ArgumentParser()
    p.add_argument("--in", dest="src", required=True)
    p.add_argument("--expect", required=True, help="WxH e.g. 2560x1440")
    a = p.parse_args()
    img = Image.open(a.src).convert("RGB")
    w, h = img.size
    ew, eh = map(int, a.expect.split("x"))
    fails = []
    if (w, h) != (ew, eh): fails.append(f"V1 size {w}x{h} != {ew}x{eh}")
    if w % 16 or h % 16: fails.append(f"V2 not 16-divisible")
    px = list(img.getdata())
    n = len(px)
    warm = sum(1 for r,g,b in px if r > g > b)
    cool = sum(1 for r,g,b in px if b > r)
    neon = sum(1 for r,g,b in px if max(r,g,b) > 178 and (max(r,g,b)-min(r,g,b)) > 128)
    black = sum(1 for r,g,b in px if r==0 and g==0 and b==0)
    white = sum(1 for r,g,b in px if r==255 and g==255 and b==255)
    if black: fails.append(f"V3 pure black pixels: {black}")
    if white: fails.append(f"V4 pure white pixels: {white}")
    if warm/n < 0.55: fails.append(f"V5 warm ratio {warm/n:.2%} < 55%")
    if cool/n > 0.30: fails.append(f"V6 cool ratio {cool/n:.2%} > 30%")
    if neon/n > 0.005: fails.append(f"V7 neon ratio {neon/n:.2%} > 0.5%")
    if fails:
        print("FAIL"); [print(" -", f) for f in fails]; sys.exit(1)
    print(f"PASS {a.src} {w}x{h} warm={warm/n:.1%} cool={cool/n:.1%} neon={neon/n:.2%}")

if __name__ == "__main__":
    main()
```

### 阶段 2：编写验收脚本（先于生成）

**`tools/verify_scene_asset.py`**（最小实现，无新依赖）：

```python
#!/usr/bin/env python3
"""Verify a generated scene PNG against batch-B palette and style rules."""
from __future__ import annotations
import argparse, json, sys
from pathlib import Path
from PIL import Image

def hex_to_rgb(h): h = h.lstrip("#"); return tuple(int(h[i:i+2], 16) for i in (0, 2, 4))

def rgb_to_hsv(r, g, b):
    r, g, b = r/255, g/255, b/255
    mx, mn = max(r, g, b), min(r, g, b)
    v = mx; d = mx - mn
    s = 0 if mx == 0 else d / mx
    return s, v

def near(c, target, tol=40):
    return sum((a-b)**2 for a, b in zip(c, target)) ** 0.5 < tol

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--image", required=True)
    ap.add_argument("--scene", required=True)
    ap.add_argument("--palette", required=True)
    ap.add_argument("--report", required=True)
    args = ap.parse_args()

    pal = json.loads(Path(args.palette).read_text(encoding="utf-8"))
    g = pal["global"]; sc = pal["scenes"][args.scene]
    img = Image.open(args.image).convert("RGB")
    w, h = img.size
    px = list(img.getdata())
    n = len(px)

    warm = sum(1 for r, g_, b in px if r > b)
    sat_hi = sum(1 for r, g_, b in px if rgb_to_hsv(r, g_, b)[0] > g["max_saturation"])
    neon = sum(1 for r, g_, b in px if rgb_to_hsv(r, g_, b)[0] > 0.8 and rgb_to_hsv(r, g_, b)[1] > 0.7)
    vmin = min(rgb_to_hsv(r, g_, b)[1] for r, g_, b in px)
    vmax = max(rgb_to_hsv(r, g_, b)[1] for r, g_, b in px)
    black = sum(1 for r, g_, b in px if (r, g_, b) == (0, 0, 0))
    white = sum(1 for r, g_, b in px if (r, g_, b) == (255, 255, 255))
    primary = hex_to_rgb(sc["primary"])
    primary_hit = sum(1 for c in px if near(c, primary))

    checks = {
        "size_ok": (w, h) == (1280, 720),
        "warm_ratio": warm / n >= g["warm_ratio_min"],
        "sat_ok": sat_hi / n < 0.05,
        "neon_ok": neon / n < g["neon_ratio_max"],
        "vmin_ok": vmin >= g["min_luminance"],
        "vmax_ok": vmax <= g["max_luminance"],
        "no_black": black == 0,
        "no_white": white == 0,
        "primary_present": primary_hit / n >= 0.03,
    }
    report = {
        "image": args.image, "scene": args.scene, "size": [w, h],
        "warm_ratio": round(warm / n, 4),
        "sat_hi_ratio": round(sat_hi / n, 4),
        "neon_ratio": round(neon / n, 6),
        "vmin": round(vmin, 4), "vmax": round(vmax, 4),
        "black_px": black, "white_px": white,
        "primary_ratio": round(primary_hit / n, 4),
        "checks": checks,
        "pass": all(checks.values()),
    }
    Path(args.report).write_text(json.dumps(report, indent=2, ensure_ascii=False), encoding="utf-8")
    print(json.dumps(report, indent=2, ensure_ascii=False))
    return 0 if report["pass"] else 1

if __name__ == "__main__":
    sys.exit(main())
```

**幂等 upsert 脚本** `tools/upsert_visual_binding.py`（避免重复追加）：

```python
#!/usr/bin/env python3
import argparse, csv
from pathlib import Path

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--csv", required=True)
    ap.add_argument("--type", required=True)
    ap.add_argument("--id", required=True)
    ap.add_argument("--sprite", default="")
    ap.add_argument("--portrait", default="")
    ap.add_argument("--icon", default="")
    ap.add_argument("--font", default="font.body")
    args = ap.parse_args()

    p = Path(args.csv)
    rows = list(csv.DictReader(p.open(encoding="utf-8")))
    fields = ["binding_type", "binding_id", "sprite_key", "portrait_key", "icon_key", "font_role"]
    new = {"binding_type": args.type, "binding_id": args.id,
           "sprite_key": args.sprite, "portrait_key": args.portrait,
           "icon_key": args.icon, "font_role": args.font}
    found = False
    for r in rows:
        if r["binding_type"] == args.type and r["binding_id"] == args.id:
            r.update(new); found = True
    if not found:
        rows.append(new)
    with p.open("w", encoding="utf-8", newline="") as f:
        w = csv.DictWriter(f, fieldnames=fields)
        w.writeheader(); w.writerows(rows)
    print(f"upserted {args.type}/{args.id} (new={not found})")

if __name__ == "__main__":
    main()
```

## A. 主方案（art-002-batch-b）致命问题

### A1. 【死代码】`snap_to_grid.py` 是空操作，验收 V2 是假通过
脚本只做 `assert w % 16 == 0`，然后原样保存。2560/1440 本来就整除 16，**这个脚本对任何输入都只会"通过"或"崩溃"，永远不会改变像素**。方案 §2.1 自己承认"不做像素级重绘"，但 §4.1 V2 却把它当验收项——**V2 恒真，等于没验**。

**返工要求**：
- 删除 `snap_to_grid.py`，或改名为 `assert_grid_divisible.py` 并明确它只是断言。
- V2 必须改为**可失败的检查**：例如检测建筑边缘/道路边缘的像素梯度是否落在 16 倍数坐标上（用 Sobel 或简单差分找边缘列/行，统计 `x % 16 == 0` 的边缘占比 ≥ 阈值）。否则删掉 V2，别假装有网格验收。

### A2. 【不可触达机制】分块拼接的"跨块锚点"在 FLUX 下不可控
方案要求 4 块用**同一 seed** 保证风格一致，但 FLUX 的 seed 只保证**同 prompt 同尺寸**可复现；4 块 prompt 不同（方位描述不同），同 seed 不产生任何跨块一致性。更致命的是：**"a wide brick-paved avenue runs horizontally through the middle"** 这种文字锚点在 diffusion 模型里是**概率性**的——TL 块的大道可能在 y=400，TR 块可能在 y=600，拼接后直接断裂。

**返工要求**：
- 放弃"文字锚点保证拼接"的幻想。改为**生成后强制对齐**：拼接前对相邻块做边缘匹配（在接缝 ±32px 内做互相关，找最佳偏移），或
- 改为**单张 2048×1152 生成 + 内容感知放大到 2560×1440**（Real-ESRGAN 或 PIL LANCZOS），并在生成记录里**如实标注"非原生 2560"**。方案 §0 G0.7 的"裁决：优先分块"缺乏依据，应改为"优先单张+放大，分块仅作 fallback"。
- 无论选哪条，V11/V12 必须**自动化**（接缝两侧 16px 带的颜色直方图距离 < 阈值），不能只靠"目检"。

### A3. 【存档/单源风险】visual_bindings 建议行与 scene_metadata 的 key 不一致
主方案 §5.4 建议 `scene,commercial_district,scene.commercial_district.background`，但 §5.4 第 2 条的 scene_metadata 行是 `commercial_district,商业区,scene.commercial_district.background,...`。**问题**：G0.6 说"若未注册则本批不写 scene_metadata"，但 §5.4 又给出了 scene_metadata 的行内容——**这是死代码**，因为按 G0.6 逻辑这批大概率不写。更严重的是：如果 world-001 后续用**不同的 sprite_key 命名**（如 `scene.commercial.bg`），本批的 visual_bindings 建议行会**指向不存在的资源**，运行时 `get_resolved_asset_path` 回退到基线，**资产静默不可达**。

**返工要求**：
- 在 G0.6 里**强制**先读 `data/scene_metadata.csv` 和 `data/visual_bindings.csv` 的**现有列名与 key 命名规范**，把结果写进 `docs/ART_FACTS.md`。
- visual_bindings 建议行的 `sprite_key` 必须与 scene_metadata 的 `background_key` 列**逐字符一致**，并在建议文档里附上"一致性校验命令"：
  ```bash
  # 必须输出 0 行差异
  comm -3 <(cut -d, -f3 docs/.../bindings.csv | sort) <(cut -d, -f3 data/scene_metadata.csv | sort)
  ```
- 若 G0.6 判定未注册，则**本批不产出任何 visual_bindings 行**，只产出"待 world-001 注册后由接入方生成"的说明。否则就是制造孤儿绑定。

### A4. 【验收漏洞】V3/V4 只查纯黑纯白，漏掉"近黑近白"
`min(R,G,B) > 0x1A` 的意图是禁纯黑，但脚本里 `black = sum(... if r==0 and g==0 and b==0)` 只统计**精确 (0,0,0)**。FLUX 输出几乎不会有精确 0，所以 V3 恒真。V4 同理。**这两个验收项是装饰性的。**

**返工要求**：
- V3 改为 `sum(1 for r,g,b in px if max(r,g,b) < 0x1A) / n < 0.001`（近黑占比）。
- V4 改为 `sum(1 for r,g,b in px if min(r,g,b) > 0xF0) / n < 0.001`（近白占比）。
- 并加一条 **V3b：暗部占比** `sum(1 for r,g,b in px if max(r,g,b) < 0x40) / n < 0.05`，防止"温柔治愈"图整体压暗。

### A5. 【测试漏洞】V5 暖色占比 `R > G > B` 对灰色/中性色误判
`#636F7C`（石板灰，R<G<B）是主色之一，但 V5 要求 `R>G>B` 占比 ≥55%。**主色本身不满足暖色定义**，方案却把它列为主色。这会导致：要么 V5 永远不过，要么生成图偏离主色。**规格表与验收标准自相矛盾。**

**返工要求**：
- 重新定义"暖色"：`R >= B`（而非 `R > G > B`），或
- 把主色 `#636F7C` 从"主色"降为"辅助中性色"，主色改为 `#CD7E60` 暖砖。二选一，写进规格表并同步改 V5。
- 加一条 **V5b：主色命中率** `near(px, primary) / n >= 0.03`，确保生成图真的用了规格表里的色。

## B. 独立方案（art-002-batch-b-independent）致命问题

### B1. 【验收脚本 bug】`rgb_to_hsv` 返回 `(s, v)` 但调用处当 `(h, s, v)` 用
```python
def rgb_to_hsv(r, g, b):
    ...
    return s, v          # 只返回 2 个值

# 调用处：
sat_hi = sum(1 for r, g_, b in px if rgb_to_hsv(r, g_, b)[0] > g["max_saturation"])
# [0] 拿到的是 s，OK
neon = sum(1 for r, g_, b in px if rgb_to_hsv(r, g_, b)[0] > 0.8 and rgb_to_hsv(r, g_, b)[1] > 0.7)
# [0]=s, [1]=v，逻辑上"高饱和高亮"勉强对
vmin = min(rgb_to_hsv(r, g_, b)[1] for r, g_, b in px)   # [1]=v，OK
```
**表面能跑，但 `neon` 判据是 `s>0.8 and v>0.7`，而 `sat_hi` 判据是 `s>0.55`。** 问题在于：`max_saturation=0.55` 时 `sat_hi/n < 0.05` 要求 95% 像素饱和度低于 0.55——**这对任何真实照片/渲染图都极难达到**。FLUX 输出的自然图像饱和度中位数通常在 0.3–0.6，会有大量像素超 0.55。**这条验收大概率恒失败，导致无限重试。**

**返工要求**：
- 先跑一次生成，**实测** `sat_hi_ratio` 分布，再定阈值。不要拍脑袋写 0.05。
- 或改为**分位数判据**：`P95(saturation) < 0.55`，比"占比 < 5%"更稳健。
- `neon` 判据改为标准 HSV：`h in [270,330] or h in [160,200]`（紫/青）且 `s>0.7 and v>0.7`，而不是只看 s/v。当前实现会把**任何高饱和暖色**（如正红、正橙）误判为霓虹。

### B2. 【自相矛盾】§0 说"不采纳 art-001 门禁路线"，§7 步骤 11 又写"改 scene_metadata + SceneRouter"
§0 表格明确"登记方式：改 CSV + 生成 ASSET_LICENSES 记录"，§4 阶段 6 直接 `upsert_visual_binding.py` 写 `data/visual_bindings.csv`，阶段 7 又写 `scene_metadata.csv` 和 `SceneRouter.VALID_AREAS`。**这与主方案 G0.6 的"不写 scene_metadata/SceneRouter，交给 world-001"直接冲突。** 两份方案对同一文件的写权限判断相反，**必须裁决，否则两个 Agent 会互相覆盖。**

**返工要求**：
- 独立方案必须**明确声明**：`data/scene_metadata.csv` 和 `scripts/scene_router.gd` 的**唯一写入方**是谁。若 world-001 是 owner，则阶段 7 删除，改为"输出待注册行到 `docs/.../pending_registration.csv`"。
- `data/visual_bindings.csv` 同理：若 G0.3 未裁决读取方式，`upsert_visual_binding.py` 的 `DictWriter` 会**重写整个文件**（`w.writeheader()` + `writerows`），**丢失原有列顺序和注释**。这是**存档级风险**。

### B3. 【存档风险】`upsert_visual_binding.py` 会破坏 CSV 原有结构
```python
fields = ["binding_type", "binding_id", "sprite_key", "portrait_key", "icon_key", "font_role"]
w = csv.DictWriter(f, fieldnames=fields)
w.writeheader(); w.writerows(rows)
```
- 若原 CSV 列名不同（如 `type,id,sprite`），**所有原有行会被写成空值**（DictReader 读不到新列名）。
- 若原 CSV 有额外列，**被静默丢弃**。
- 若原 CSV 有 BOM 或注释行，**被破坏**。

**返工要求**：
- 改为**读原 header**：`reader.fieldnames` 作为 `fieldnames`，新行用 `defaultdict` 补空。
- 写前**备份** `data/visual_bindings.csv.bak.<timestamp>`。
- 加**原子写**：写临时文件 + `os.replace`。
- 加**dry-run 模式**：`--dry-run` 只打印 diff 不写盘。
- 加**幂等断言**：写后重新读取，断言行数 = 原行数 + 新增数，且原有行内容逐字节不变。

### B4. 【不可触达】`industrial_zone` vs 主方案 `industrial_district` key 冲突
独立方案用 `industrial_zone`，主方案用 `industrial_district`。**两份方案对同一场景给了不同 key。** 如果两个 Agent 都执行，会产生**两个目录、两条绑定、两个场景**，其中一个永远不被 SceneRouter 引用（死资产）。

### B5. 【测试漏洞】`primary_present` 用欧氏距离 < 40 判"主色出现"
`#C9A88A` 与 `#D9C4A0` 的欧氏距离 = √(16²+28²+22²) ≈ 39.4 < 40。**卧室主色会被商业区主色误判命中。** 三张图的色板互相污染，`primary_present` 失去区分力。

```python
#!/usr/bin/env python3
"""Verify a generated scene PNG against batch-B palette and style rules (v2)."""
from __future__ import annotations
import argparse, json, sys
from pathlib import Path
from PIL import Image

def hex_to_rgb(h):
    h = h.lstrip("#")
    return tuple(int(h[i:i+2], 16) for i in (0, 2, 4))

def rgb_to_hsv(r, g, b):
    r, g, b = r/255, g/255, b/255
    mx, mn = max(r, g, b), min(r, g, b)
    v = mx
    d = mx - mn
    s = 0 if mx == 0 else d / mx
    if d == 0:
        h = 0
    elif mx == r:
        h = (60 * ((g - b) / d) + 360) % 360
    elif mx == g:
        h = 60 * ((b - r) / d) + 120
    else:
        h = 60 * ((r - g) / d) + 240
    return h, s, v

def quantize_top1(px):
    """8-color quantize, return top-1 cluster center."""
    img = Image.new("RGB", (len(px), 1))
    img.putdata(px)
    q = img.quantize(colors=8, method=Image.Quantize.MEDIANCUT)
    pal = q.getpalette()
    counts = q.getcolors()
    counts.sort(reverse=True)
    idx = counts[0][1]
    return tuple(pal[idx*3:idx*3+3])

def edge_grid_ratio(px, w, h, grid=16):
    """Fraction of strong vertical edges whose x % grid == 0."""
    gray = [0.299*r + 0.587*g + 0.114*b for r, g, b in px]
    edges = 0
    on_grid = 0
    for x in range(1, w):
        for y in range(0, h, 4):
            i = y*w + x
            if abs(gray[i] - gray[i-1]) > 40:
                edges += 1
                if x % grid == 0:
                    on_grid += 1
    return on_grid / edges if edges else 0.0

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--image", required=True)
    ap.add_argument("--scene", required=True)
    ap.add_argument("--palette", required=True)
    ap.add_argument("--report", required=True)
    args = ap.parse_args()

    pal = json.loads(Path(args.palette).read_text(encoding="utf-8"))
    g = pal["global"]
    sc = pal["scenes"][args.scene]
    img = Image.open(args.image).convert("RGB")
    w, h = img.size
    px = list(img.getdata())
    n = len(px)

    hsv = [rgb_to_hsv(*c) for c in px]
    sats = sorted(s for _, s, _ in hsv)
    p95_sat = sats[int(n * 0.95)]
    vmin = min(v for _, _, v in hsv)
    vmax = max(v for _, _, v in hsv)

    warm = sum(1 for r, g_, b in px if r >= b)
    neon = sum(1 for hh, s, v in hsv
               if (270 <= hh <= 330 or 160 <= hh <= 200) and s > 0.7 and v > 0.7)
    near_black = sum(1 for r, g_, b in px if max(r, g_, b) < 0x1A)
    near_white = sum(1 for r, g_, b in px if min(r, g_, b) > 0xF0)
    dark = sum(1 for r, g_, b in px if max(r, g_, b) < 0x40)

    top1 = quantize_top1(px)
    primary = hex_to_rgb(sc["primary"])
    primary_dist = sum((a-b)**2 for a, b in zip(top1, primary)) ** 0.5

    eg_ratio = edge_grid_ratio(px, w, h, 16)

    checks = {
        "size_ok": (w, h) == tuple(sc["final_size"]),
        "warm_ratio": warm / n >= g["warm_ratio_min"],
        "sat_p95_ok": p95_sat < g["max_saturation_p95"],
        "neon_ok": neon / n < g["neon_ratio_max"],
        "vmin_ok": vmin >= g["min_luminance"],
        "vmax_ok": vmax <= g["max_luminance"],
        "near_black_ok": near_black / n < g["near_black_ratio_max"],
        "near_white_ok": near_white / n < g["near_white_ratio_max"],
        "dark_ok": dark / n < g["dark_ratio_max"],
        "primary_top1_ok": primary_dist < g["primary_top1_dist_max"],
        "edge_grid_ok": eg_ratio >= g["edge_grid_ratio_min"],
    }
    report = {
        "image": args.image, "scene": args.scene, "size": [w, h],
        "warm_ratio": round(warm/n, 4),
        "sat_p95": round(p95_sat, 4),
        "neon_ratio": round(neon/n, 6),
        "vmin": round(vmin, 4), "vmax": round(vmax, 4),
        "near_black_ratio": round(near_black/n, 6),
        "near_white_ratio": round(near_white/n, 6),
        "dark_ratio": round(dark/n, 4),
        "top1_color": list(top1), "primary_dist": round(primary_dist, 2),
        "edge_grid_ratio": round(eg_ratio, 4),
        "checks": checks, "pass": all(checks.values()),
    }
    Path(args.report).write_text(json.dumps(report, indent=2, ensure_ascii=False), encoding="utf-8")
    print(json.dumps(report, indent=2, ensure_ascii=False))
    return 0 if report["pass"] else 1

if __name__ == "__main__":
    sys.exit(main())
```

```python
#!/usr/bin/env python3
"""LANCZOS upscale a scene PNG to target size."""
import argparse, sys
from PIL import Image

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--in", dest="src", required=True)
    ap.add_argument("--out", required=True)
    ap.add_argument("--width", type=int, required=True)
    ap.add_argument("--height", type=int, required=True)
    a = ap.parse_args()
    img = Image.open(a.src).convert("RGB")
    if img.size == (a.width, a.height):
        img.save(a.out, "PNG", optimize=True)
        print(f"NOOP {a.out} already {a.width}x{a.height}")
        return 0
    up = img.resize((a.width, a.height), Image.LANCZOS)
    up.save(a.out, "PNG", optimize=True)
    print(f"UPSCALED {a.src} {img.size} -> {a.out} {up.size}")
    return 0

if __name__ == "__main__":
    sys.exit(main())
```

```python
#!/usr/bin/env python3
"""Simulate PresentationManager.get_resolved_asset_path for pending bindings."""
import argparse, csv, sys
from pathlib import Path

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--pending", required=True)
    ap.add_argument("--root", default=".")
    a = ap.parse_args()
    root = Path(a.root)
    fails = []
    with open(a.pending, encoding="utf-8") as f:
        for row in csv.DictReader(f):
            sprite = row.get("sprite_key", "")
            if not sprite:
                continue
            # sprite_key 形如 scene.commercial_district.background
            parts = sprite.split(".")
            if len(parts) < 3 or parts[0] != "scene":
                fails.append(f"bad sprite_key format: {sprite}")
                continue
            scene_key = parts[1]
            path = root / "assets/art/formal/scenes" / scene_key / "background.png"
            if not path.exists():
                fails.append(f"missing: {path} (from {sprite})")
            else:
                print(f"OK {sprite} -> {path}")
    if fails:
        print("FAIL"); [print(" -", x) for x in fails]; sys.exit(1)
    print("PASS all bindings resolvable")

if __name__ == "__main__":
    sys.exit(main())
```
