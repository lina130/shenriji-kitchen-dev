# 《深城日常》0.5.0 设计补充：商品流水线 + 城中村招工

## 一、不同商品 = 不同生产流水线

保留“备料 → 加工 → 出餐”的手作流程，但**每个商品有自己的工序链**，不是所有菜都走同一条线。

### 商品流水线示例

| 商品 | 工序链 | 用到的工位 |
|---|---|---|
| 鲜肉包 | 和面 → 包馅 → 上笼蒸 → 出笼 | 备料台 → 备料台 → 蒸笼 → 出餐台 |
| 现磨豆浆 | 泡豆 → 磨浆 → 煮浆 → 装杯 | 备料台 → 磨浆机 → 灶台 → 出餐台 |
| 现炸油条 | 和面 → 擀面 → 下锅炸 → 沥油 | 备料台 → 备料台 → 油锅 → 出餐台 |
| 皮蛋瘦肉粥 | 淘米 → 下料 → 慢熬 → 盛碗 | 备料台 → 备料台 → 砂锅 → 出餐台 |
| 汤河粉 | 熬汤 → 烫粉 → 加料 → 出碗 | 灶台 → 汤锅 → 备料台 → 出餐台 |
| 蛋炒饭 | 备料 → 下锅炒 → 装盘 | 备料台 → 灶台 → 出餐台 |
| 手打柠檬茶 | 泡茶 → 捶柠檬 → 加冰 → 封杯 | 备料台 → 备料台 → 饮品台 → 出餐台 |

### 系统落地方式
- 数据表 `data/recipes.csv` 增加 `pipeline` 字段，例如 `prep:2.4|wrap:1.8|steam:4.0|serve:0.6`，每段带 `阶段:耗时`。
- 阶段带**工位类型**要求：备料类只能在备料台做，蒸/炸/煮只能在对应灶具，出餐在出餐台。
- 半成品可以**暂存**在工位或托盘上，玩家要自己挪过去，形成真实的忙乱感。
- 不同阶段消耗不同资源：备料耗劳力，蒸煮炸耗时间与燃料，装盘耗脑力。
- 同一条街上会出现“早餐三件套（包/浆/条）”和“夜市菜”两种节奏完全不同的流水线。
- 设备升级只加速/扩容对应工位，不通吃：升级蒸笼不影响油锅。

## 二、深圳城中村式招聘与离职

不是“花钱买永久工人”，而是**有诉求、会走人**的活人。

### 每个打工人带的东西
- **期望工资**：随角色、技能、季节浮动。春节前普遍上涨，节后回落。
- **诉求（traits）**：攒钱寄回家 / 想学一门手艺 / 要照顾小孩老人 / 想离家近 / 打算跳去工厂 / 想自己开个小店。
- **状态**：士气、疲劳、被欠薪天数、有没有包住。
- **技能**：备料熟练度、灶台熟练度、出餐速度，可通过干活慢慢涨。

### 离职触发（符合城中村现实）
- 连续欠薪，或长期工资低于期望
- 长期加班、疲劳过高、士气低落
- 春节返乡潮：节前离职概率明显升高，节后又有回流机会
- 学够手艺后自己出去摆摊/开店（徒弟出师会走）
- 被工厂涨薪挖走、被隔壁店挖走
- 家人生病、回老家办事等突发事由

### 留人手段（也有代价）
- 加薪、发年终奖、包吃包住
- 排班调休、降低疲劳
- 教手艺——能提升产出，但要接受“他学会就可能走”
- 帮忙介绍工作/垫路费——短期亏钱，长期积累老乡口碑，以后更好招人

### 招人渠道
- 劳务市场：人多但技能参差，要面试
- 老乡介绍：可靠但会带来人情债
- 熟人推荐（NPC 关系达标）：技能高、留得久
- 招聘成本、试用期、以及“来了一天就走的日结工”

### 与现有系统的关系
- 复用 `StaffManager`（已驻店/工钱）并扩展为“员工档案 + 士气 + 离职判定”
- 复用 `RelationshipManager` 做熟人推荐门槛
- 复用 `CalendarManager` 做春节返乡潮
- 复用 0.5.0 已完成的：农场（原料）、宠物/房间（生活加成）、NPC 作息

## 四、按时段轮换商品（早市 / 午市 / 晚市）

商品不是固定清单，而是**跟着一天的时间段换**：

| 时段 | 大致时间 | 卖什么 | 节奏 |
|---|---|---|---|
| 早市 | 06:00–10:30 | 鲜肉包、现磨豆浆、现炸油条、皮蛋瘦肉粥、茶叶蛋、汤河粉 | 快、量大、客单价低 |
| 午市 | 10:30–15:00 | 蛋炒饭、鸡腿饭、汤河粉、快餐套餐、手打柠檬茶 | 出餐快、翻台高 |
| 晚市 | 17:00–23:00 | 夜市烤肉、牛肉面、炒粉、柠檬茶、糖水 | 客单价高、工序多、耐心低 |

- 每个时段有**独立的菜单池**，同一商品可跨时段出现但价格/需求不同。
- 换市时会有过渡（备料清空、设备切换），不是瞬间跳变。
- 赶不上时段就错过客流，鼓励玩家安排一天的节奏。

## 五、一天的长度

- 目前 1 现实秒 = 1 游戏分钟（0.4 秒/分已改慢到 1.1 秒/分）。
- 0.5.0 计划把**一天拉长到现实约 40–50 分钟**（1 现实秒 ≈ 0.5 游戏分钟），让早/午/晚三个市都玩得开、也留出跑腿和照料宠物/农场的时间。
- 睡觉、营业、外出都会各自推进时间；具体倍率做成配置项，方便平衡。

## 六、自动存档（硬性要求）

必须稳定，不能丢档：
- **定时自动存档**：每游戏内 N 分钟（例如每 15 游戏分钟）落盘一次，节流避免频繁写盘。
- **关键节点自动存档**：换市、开/关档、睡觉、进货、买卖、雇人/离职、种收、宠物行动、买房具、存档点事件。
- **原子写入**：先写临时文件再原子替换，避免写一半崩溃损坏存档。
- **轮转备份**：保留最近 3 个存档（save / save.bak1 / save.bak2），损坏时自动回退。
- **版本兼容**：存档带版本号，旧档能迁移读取，读档失败给明确提示且不覆盖原档。
- **崩溃安全**：进程异常退出后重启能读到最近一次自动存档。
- **手动存档**（F5）与自动存档并存，互不覆盖。
