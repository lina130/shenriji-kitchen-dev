# 深圳一城可玩原型：地图蓝图

本阶段只把深圳做成能打开、能玩、能存档的完整原型。现有大湾区总览是技术草图，不作为首版完成度；其他城市留到深圳的玩法与美术通过实机验收之后。

## 地理依据与改编尺度

- 底图依据：深圳市规划和自然资源局监制的[深圳市地图](https://pnr.sz.gov.cn/ywzy/chgl/chzxfw/szmap/201908/P020190820536204847870.pdf)，以及深圳市民政局的[行政区划概况](https://mzj.sz.gov.cn/szmz/pc/bmxx/cyfwzy/content/post_2949169.html)。以官方图上的海岸、山地、主要城区方位和道路联系校对游戏地图。
- 深圳西濒珠江口，南临深圳湾和香港方向，东临大鹏湾与大亚湾。游戏采用可步行、可缩放的压缩空间，保留方位及空间关系，不按真实比例复制街道或导航数据。
- 西到东的首版骨架：宝安与前海入口 → 南头、蛇口、深圳湾 → 福田中心与滨海 → 罗湖旧城 → 盐田海岸 → 大鹏山海。北侧连接光明、龙华、龙岗、坪山的形态和交通节点；密度与可交互内容分批完成。
- 镜头可自由旋转、俯仰和缩放；全貌读出地形与片区，步行视角读出店面、摊位、人、车与生活细节。地面不叠加悬浮地点文字，招牌作为建筑材质可有文字。

## 首版密度分配

1. **可玩核心：南头—科技园—深圳湾。** 连续步行街网，精做老街茶铺、街角经营、创意工作室、跑单驿站、滨海步道。三条职业、住房、消费、邻里、收集与存档在这里闭环。
2. **城市骨架：前海、蛇口、福田、罗湖、盐田和大鹏。** 先做各自可辨的地形、道路、水岸、建筑群轮廓和至少一个可到达的生活节点，避免只有天际线模型。
3. **北侧背景与后续填充：宝安、光明、龙华、龙岗、坪山。** 首版保障连续地图和方向正确，逐批用街区、交通及可玩内容替换远景占位。

## 游玩验收

- 从主菜单一键进入深圳，在市域全貌与街景之间缩放、转向；可沿道路连续步行，不能穿海或从道路接缝坠落。
- 在深圳场景里亲手取物、加工、交付，完成餐饮、跑单、创意各一条完整路线；悠闲与忙碌班收益明显不同。
- 一天内能工作、消费、和邻居来往、布置或收集、休息；可选稀有发现来自日常互动中不张扬的一次性彩蛋，无每日固定寻宝点。
- 中途退出后能恢复钱、精力、天数、背包、角色位置与进行中的工作；用户原有存档保持可读。
- 每批正式建筑、人物、物品和场景素材留有源文件、实机画面和验收记录；程序几何只作为施工占位。

## 当前差距

当前项目已有可运行的微3D预览、转向缩放、三个邻接街块、三条短职业循环和存档；宏观地图仍是11城抽象草图，深圳街区位置关系、道路与地标未达到本蓝图。旧的每日搜索箱子与线索牌不符合彩蛋定调，需要替换。此页记录目标，不把占位计为完成。
