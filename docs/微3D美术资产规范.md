# 微 3D 美术资产规范

状态：制作规范 v0.1。2026-09-27。当前 `scripts/city3d` 中的方盒和球体仅是验证镜头、比例、碰撞与交互的 **blockout**，不能计入正式美术完成量。

用户提供的六张参考图已经定调。先读 [美术定调：可游玩的微缩湾区](美术定调_微缩湾区.md)；本文的数值与流程服从该画面目标。

## 视觉目标

- 可旋转、可缩放的斜俯视镜头下，近景像一座可走入的温暖城市微缩模型，远景可看清整个湾区的地形与城市分布。人物和建筑有真实厚度、圆润边缘、清晰剪影；色彩明亮但不过曝。
- 深圳的城中村、骑楼街、科技园、口岸、海边，与香港的坡道、街市、渡轮、密集招牌等视觉语汇要经过实地/官方图像参考整理，再做原创概括。其他九城也各有自己的建筑、植被、店面和生活器物。
- “可爱”来自比例、材质和动画节奏；不用让每种物体都变成同一种塑料玩具。招牌、街道、人物服装、食物要有生活质感。
- 多角度可读性优先：门与可互动物在正常游玩高度、镜头绕转和近景缩放后都应可辨；屋顶、树冠和高楼需处理遮挡。总览缩放时依靠地形、道路、水系与建筑剪影辨城，不把文字直接铺在地图上。

## 资产规格与制作顺序

| 类别 | 首批英雄资产 | 必备检查 |
|---|---|---|
| 角色 | 玩家基础体型、陈伯、小林、顾客原型 | 正侧背剪影、肤色与服装层次、走路/待机/互动动作、表情可读 |
| 建筑 | 出租屋、茶铺/早餐店、跑单驿站、创意工作室 | 屋顶与立面分层、真实门口、招牌、窗台与空调/雨棚等细节、室内入口 |
| 街道 | 道路、人行道、路沿、树池、斑马线、公交/骑行设施 | 可连续拼接、行走与碰撞一致、昼夜/雨天材质表现 |
| 道具 | 餐具、食物、跑单箱、相机与创作工具、家具 | 握持尺寸、近景轮廓、与交互动画对齐 |
| UI | HUD、背包、现场操作与对话卡 | 与 3D 画面统一色彩；小分辨率可读；不遮挡关键动作 |

每个正式资产须记录：唯一 ID、所属城市与类别、源文件、导出文件、真实世界尺寸、主材质、LOD/面数预算、碰撞形状、动画、授权/生成来源、实机截图、审核状态。建模源文件优先可编辑格式，运行时导出 glTF/GLB。当前已配置 `.tools/blender/blender-5.2.1-windows-x64/blender.exe` 便携版；Godot 原生网格只继续承担占位与程序化重复件，不能替代所有正式模型。

## 质量门禁

1. **单资产**：在正常相机距离和近景各看一次，形状一眼能认出；材质无过曝、闪烁、穿模和明显贴图拉伸。
2. **套件**：同一街区至少做日间、夜间、雨天三张实机截图，审查色彩、灯光、遮挡、招牌阅读和街区辨识度。
3. **动作**：玩家移动、对话、工作、持物、坐下和经营交互要有起止反馈；动作不能穿门、台面或道具。
4. **性能**：记录代表性街区 1080p 帧率和绘制调用；重复物件使用实例化/LOD，远景减面，近景保留细节。
5. **来源**：外部模型、字体、纹理、音效有清楚许可；参考游戏的图像与角色只用于设计研究，不直接复制进资源。

先把玩家、一个完整店面、一个完整街道套件和一个 NPC 做到上述标准，再扩展到大量城市素材。自动任务不得把“生成了很多图/模型”当成美术验收。

## 首批城市参考与建模方向

场景结构依据官方资料提炼，**不复制照片、建筑图纸或参考游戏资产**：深圳市规划和自然资源局对[南头古城的保护与更新](https://zjj.sz.gov.cn/gkmlpt/content/12/12666/post_12666623.html)提供旧城肌理与新用途并置的参考；香港旅游发展局介绍[春秧街市与穿行街市的电车](https://www.discoverhongkong.com/eng/place-to-go/travel.guide-chun-yeung-street-wet-market.html)。游戏将其概括成原创的南头旧巷石地面、混合店面与香港电车街市摊档。
