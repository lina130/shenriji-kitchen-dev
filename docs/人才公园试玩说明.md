# 人才公园湖畔餐馆 · 试玩说明

这是《深城日常》的独立微 3D 开发试玩，当前聚焦深圳湾人才公园、湖畔餐馆和后海商圈地标。新版与旧版 2D 使用不同入口和存档。

## 启动与操作

直接双击 `release/windows/人才公园餐馆试玩.exe` 即可进入新版餐馆厨房，不需要先打开 Godot 或在公园寻找入口。开发中的最新代码可从仓库根目录双击 `试玩人才公园.cmd`；如需重新导出 EXE，运行 `构建人才公园试玩.ps1`。试玩期间始终留在厨房；打烊后在结算页继续营业，关闭窗口时自动保存。旧 2D 请单独双击 `旧版2D.cmd`。新版默认以带标题栏的最大化窗口占满屏幕可用区域，可最小化或还原后自由调整大小。

试玩 EXE 与旧版使用不同入口和存档；当前仍由同一个 Godot 项目导出，安装包内部尚包含旧版资源，之后会继续拆分打包。构建脚本只导出这个试玩文件并检查新版入口，不会重建旧版发布包或清理存档。

| 操作 | 作用 |
|---|---|
| WASD | 移动角色 |
| 鼠标左键 | 公园中点击地面前往、点击入口进入；营业时直接点击厨房实物与订单票 |
| E | 与附近高亮物件互动 |
| 厨房内鼠标左键 | 点餐票、原料、工位实物和成品；镜头固定，拖动不会移动画面 |
| M | 切换人才公园区域总览；再按一次返回店前视角 |
| P | 暂停 / 继续；暂停时顾客耐心、加热与角色操作一同停止 |
| F5 | 立即保存当前试玩进度 |
| F2 / 左上「已完成素材」 | 在公园打开3D素材展厅，查看已完成的模型；可旋转、缩放、切换 |
| Esc | 留在当前厨房画面 |

切换到其它窗口时会自动暂停并保存，返回游戏窗口后继续；若之前按 P 手动暂停，回到窗口后仍需按 P 继续。按 WASD 或 E 会取消尚未执行的点击指令，进入总览或素材展厅时也会取消。

## 开店与打烊

1. 打开后**直接在厨房营业**，顾客与餐票已经出现，无须开班；左侧旧版两枚班铃已移除。新档起始有 120 贝，也可先备货再接单。游戏时间与早、午、晚市不断循环，订单会持续补进来。想结束时，点击右侧收银区域的实体卷帘开关，进入当次营业结算；结算页可以继续营业。
2. 九个操作位排成三行三列，鼠标直接点水槽、切板、搅拌碗、腌制盘、分装托盘、点缀盘、蒸笼、煎锅和汤锅。未开做的餐票在右上角，点一次便移到左上角；之后直接点操作台上属于那道菜的食物，工序会按所点的食物推进，底栏也跟着显示它的最新流程。再点餐票只用于查看流程。两三道菜在同一个工位时各占一个可独立点击的位置。最后一步直接点前排有专属灯光的交接板上的成品菜。镜头固定，餐票、食材签与实物不会因拖动视角错位。餐票展示菜名、成品图、当前工位图、所需原料小图与备料份数、耐心条，并标出“未做／在做／已好”；缺料时该道菜直接显示“缺料”，对应原料小签显示 0，补货后实时恢复。底栏展示与餐票相同的工位图步骤、已完成勾号和当前动作；缺料时对应原料上方出现小气泡。锅里等待时可继续做另一份菜；各菜的原料、中间体和成品随工序变化。
3. 左侧是固定的二十格备料墙，四排各五种原料，位置始终不变。每格后半是仓库存料，前半是浅色食材签，标有与餐票一致的小图、单字和当前已备份数；选中餐票缺料时，对应格上方浮起食材气泡。备料格下方直接复用餐票的食材组件，图标、手写字、底色和缺料颜色同步；仓库存料模型也与餐票原料图对应。直接点所需原料一次，就会给该格备好数份原料，不需要再点准备台。每次最多备到 6 份，每种备料上限 8 份，准备区总容量 150 份；因此制作几单后需要按缺料格补充。仓库存料不足时，同一次点击会先自动进货，仓库总容量 400 份、每种上限 28 份。原料和备料数量随独立存档保存。前排保鲜架仍可制作米浆底料和香料油，每批三份，分别省去对应菜的前两步；两种底料共用八份容量并有保鲜时间。
4. 前排是一张实体备餐桌：左侧两格存米浆底料和香料油；中央双格架摆同一位顾客的两道菜，旁边一格可暂存单餐，右侧交接板显示完成的菜。做完套餐中的一道菜，直接点这道成品便会先装盘；接着点另一道菜的台面实物即可继续，底栏随之切换。两道菜都齐后，点中央整盘，店员一次取走整份餐并结算。单餐可直接交餐或暂存。缓冲餐点保鲜约 26 秒，须在顾客离开和食物变质前完成整餐。
5. 当前直接进入持续营业的常规客流，每单耐心约 88 秒，同时最多两位顾客；连续来客不会自动收班。加热完成后须及时继续，约十二秒内不取会烧焦，需要重做当前热工序并扣耐心。取出热菜后若搁置约 18 秒仍未完成，餐票会重新指向原加热工位，短时回热后才能继续后续步骤。点错动作会扣耐心并中断连击，顾客超时离开则失去该单收入；没有欠债或整局封锁。快速且连续正确交餐会提高小费和连击收益。
6. 游戏内时钟从 08:00 起，每真实一秒推进约一游戏分钟；08:00–10:59 为早市、11:00–16:59 为午市、17:00–21:59 为晚市，22:00 自动进入次日早市并继续营业。市场时段改变室内光线与窗外深圳湾日夜景、售价和顾客先点的餐：早市偏米卷、鸡蛋包与小米盅，午市偏鸡饭与拌面，晚市偏香料包与热菜；十道菜仍会轮流出现。公园可花 **15 贝**买果茶，或花 **60 贝**买一次性的海风马克杯并在店前展示；长椅可主动休息到次日。体力值不再限制游玩。

当前版本把未开做餐票放在右上、开做餐票放在左上；每道菜独立成卡。票上的原料小图直接由备料墙上的同一套 3D 原料模型渲染。厨房文字采用霞鹜文楷的手写笔画，备料签与餐票使用同一个屏幕绘制组件，不再经过低分辨率 3D 纹理，图案、字形、颜色和数量保持一致。仓库存量用尽时格内原料模型仍留在原位，食材签数字和缺料气泡显示实际状态。工位台面按水槽、切配、调制、火候和装盘用途分别配色，工作状态由器具、食材和台面细微色差表现；鼠标移到可点实物会变成手形。正向俯视镜头固定；晨光、黄昏和夜厨灯光随时钟连续变化。交接板的工作灯常亮，成品可取时再加强暖色柔光和轻微呼吸的小光点。交餐收入会以金币落入右侧收银抽屉，现金数字同步更新；顾客服装和配饰会随来客变化，偶尔说一句短话。

## 存档与当前范围

### 手机和平板网页试玩

`release/mobile/人才公园餐馆_手机网页试玩_0928.zip` 是已导出的网页试玩包。最快的分享方式是把它上传为 itch.io 的 HTML Game，ZIP 根目录已经有 `index.html`。把游戏设置为支持手机浏览器，建议使用横屏、全屏启动；只给朋友试玩时可用 Restricted 访问方式和密码。上传后发送网页链接，安卓手机、iPad、iPhone 均从浏览器打开，不需要分别安装 APK 或 iOS App。ZIP 文件本身不能直接发给手机后双击运行。

目前已在本机浏览器验证网页启动和点餐票；安卓浏览器与 iPhone/iPad Safari 尚待真机检查。手机横屏受物理屏幕高度限制，餐票与工位会比较小，iPad 更适合当前固定镜头。各设备的浏览器存档分别保存在本机浏览器中，不会与 Windows EXE 或其他朋友同步；清理站点数据可能丢失该设备进度。网页版须通过 HTTPS 网站打开。

试玩约每 10 秒自动保存一次，并在开始营业、切换客流、工序操作、交餐、打烊结算、消费、休息及退出时保存；F5 可随时手动保存。存档为 `user://talent_park_mvp.json`，保留一个 `.bak` 备份。现金、游戏时钟与天数、位置、海风杯、备货/托盘和进行中的订单可以读回。旧版 2D 存档不受影响；旧版四工位试玩的进行中班次升级后会安全结束，已到账收入保留，不会重复发放。

地图的空间关系目前根据官方导览图比例推定，场景制作以 **1 米对应 1 个 Godot 单位**为目标；尚未用实测坐标与尺寸逐点校核，所以不能称为严格 1:1 复刻。餐馆及后海地标模型已进入正式素材候选阶段，建筑细部、材质、场景丰富度与空间比例仍会继续精修。

本次试玩只有一间餐馆的厨房经营和上述最小生活消费。深圳其他街区、跑单、创意职业、住房经营、偶发彩蛋及完整大湾区地图都在后续范围。厨房的排队、加工、备货与忙碌波参考了 [Airplane Chefs 官方介绍](https://apps.apple.com/us/app/airplane-chefs-cooking-game/id1222489978)、[Shawarma Legend 官方商店页](https://store.steampowered.com/app/3036080/Shawarma_Legend/) 和 [Farm Frenzy 3 官方商店页](https://store.steampowered.com/app/38150/Farm_Frenzy_3/) 里的时间管理与加工思路，菜品、场景和数值为本项目原创。
