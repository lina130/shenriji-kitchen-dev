# 《深日记》美术定调：可游玩的微缩湾区

用户于 2026-09-27 提供八张风格参考并明确“要这种风格，定调”。本文件是后续场景、角色、UI 和模型的统一方向；参考图仅用于内部视觉研究，游戏资产均须原创制作。后续用户进一步明确：视角可以旋转与缩放到全区，地图上不放悬浮文字。

## 核心画面

- **视角**：45° 方位是默认构图，不锁死镜头。玩家可转动水平角和俯角、从街道近景缩放到全区总览；街区像能走进去的微缩模型。参考图中的独立方形底座只用于理解资产比例与展示，不作为大地图边界。
- **形体**：建筑、车、店招、树和食物都有清楚的剪影、真实厚度、圆角边缘和分层结构。近看有窗框、台阶、把手、灯、商品、植被与生活痕迹，远看仍能一眼认出用途。
- **材质与光**：哑光粉彩为底，玻璃、金属、陶瓷、布和木材有可辨材质差异；柔和天空光与方向光、接触阴影、局部高光。避免纯色平面、过曝黄地、统一塑料质感和锋利方盒边。
- **密度**：每个视窗要有主角物、次级道具、生活小件和适量留白。参考消防站、冰淇淋铺、海滨酒吧的层次，但不照搬造型、车辆、文字或配色方案。
- **城市身份**：深圳以老城肌理和新产业、口岸与滨海并置；香港有坡街、密集店招、街市、电车与渡轮；其余城市逐一建立独特的建筑、植被、交通和生活器物。地标必须是经过设计的可游玩周边空间，不只放一个孤立模型。城市方位与主要交通走廊参考[香港特区政府大湾区基础建设地图](https://www.bayarea.gov.hk/sc/connectivity/map.html)，游戏距离为了可玩性压缩。
- **UI**：卡片圆角与材质色取自场景，控制面积轻，信息清晰。视觉参考中大字标题属于展示海报，不应成为游玩 HUD；倒计时、收入、精力、藏品和交互提示必须在实际游戏分辨率下易读。
- **文字**：不在地图上叠加浮动的城市名、店名或活动说明。地点名显示在 HUD、地图界面和对话里；建筑本身可以有经过美术设计、贴在真实表面的招牌字样。

## 制作验收

1. Blender 保留 `.blend` 源文件，导出 `.glb`；重复件使用组件与材质库，碰撞在 Godot 中核对。二维插画/图标保留可编辑源文件。
2. 每个英雄资产同时查看孤立模型和正常游玩镜头；圆角轮廓、材料差异、细部可读、遮挡、阴影、性能都过关才替换占位模型。
3. 先做大湾区完整的连续地图底盘与 11 城分布，再逐区细化。首版准备把人物、物品、建筑和场景等正式美术完成到总目标约一半，之后集中推进职业、经济、创造和长期生活逻辑。地图骨架或批量占位模型不能计作已完成的正式美术。
4. 当前程序化街区是功能与比例占位，**与用户参考图仍有明显质量差距**：屋顶和墙面过平、街景过空、人物过简、招牌与 UI 未形成统一细节。后续自动任务必须优先缩小这些差距，不能把目前截图当完成标准。
