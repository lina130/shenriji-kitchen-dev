# 永久开发铁律

以下规则从项目创建起锁定，任何后续玩法、美术、联机内容均不得违反。

1. 无传统任务列表、感叹号、红点、强制目标或每日任务。
2. 无属性数值面板、精力条、健康条、情绪条、Buff 图标常驻栏。
3. 身体与情绪状态只能通过画面、动作、事件结果和短暂弱提示表达。
4. 金钱总额、时钟可用于确认基本状态；经营不做同比、环比、复杂报表。
5. 背包大容量、自动堆叠、无负重、无格子限制、一键使用。
6. 不做复杂合成、配方树、碎片拼装或材料加工负担。
7. 固定物价为基准，不做通胀、崩盘和城市级供需模拟。
8. 单机内容是完整内容；联机只做 2-4 人轻量合作，不做 PVP 和独占内容。
9. 所有职业与店铺必须有“投入 → 产出 → 成长 → 再投入”的闭环。
10. 内容正向合规，允许表现生活压力，但必须保留努力有回报和人生可翻盘。
11. 先做深核心循环，再扩展内容；前一阶段未验收不得偷跑下一阶段。
12. AI 可以无限拓展内容，但不得以丰富度为理由堆砌操作和管理维度。
