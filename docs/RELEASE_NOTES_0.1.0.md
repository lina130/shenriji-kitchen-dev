# 《深日记》0.1.0 发行说明

这是项目的首个可发行 Windows 垂直切片，重点不是一次塞入全部人生路线，而是验证完整生活循环是否成立。

## 本版内容

- 从出租屋起床开始，自由决定打工、兼职、闲逛摸金、学习、锻炼或提前休息。
- 工厂和便利店两条收入路线，天气会影响体力消耗，熟练后收益和负担自然改善。
- 旧货市场、废品回收站、街道与公园每日刷新旧物，包含普通、少见、稀有、传说四级。
- 四位 NPC 拥有日常对话、喜好礼物和隐藏关系阶段。
- 第 30 天自动交租，并出现当月生活小结；欠租会以生活化方式延续，不会突然游戏结束。
- 随机天气、昼夜色调、雨滴与潮气表现，全程不使用属性条。
- 背包、旧物册、地图、账本均为功能界面，不显示精力、健康、幸运或口碑数值。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标右键 | 核心互动 |
| E | 便捷互动 |
| I | 背包 |
| C | 旧物册 |
| M | 地图 |
| B | 生活账本 |
| F5 / F9 | 保存 / 读取 |
| Esc | 暂停、关闭界面、主菜单 |

## 发行形态

- Windows x86_64 独立执行文件。
- 不需要安装 Godot。
- 存档和设置保存在用户数据目录。
