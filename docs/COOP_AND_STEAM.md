# 合作与平台发行接口

## 轻量合作

`CoopManager` 提供 2-4 人纯合作会话接口：

- 创建主机
- 加入好友房间
- 离开房间
- 人数限制
- 主机状态
- 玩家连接/离开事件
- F6 好友与平台界面
- 场景、位置和朝向同步
- 当前场景中的远程玩家表现
- 房主权威共同经济快照
- 资金、库存、店铺、农场、员工、生意和房间同步

当前不包含 PVP、交易所或合作独占内容。玩家位置和场景同步，以及房主权威的共同资金、库存、店铺、农场、员工、生意和房间快照已经接入。访客的核心共同交易会在本地被拦截，避免写出与房主不一致的账本；批发买卖、店铺升级、农场种植/养殖、夜市交易和厨房班次/订单/工位操作已支持逐笔远程请求 RPC；厨房进度会随共同快照回传。

## Steam 与平台

`PlatformIntegrationManager` 提供：

- Steam 插件检测
- 成就提交
- 统计值提交
- 云存档能力检测
- 无 Steam 环境下的本地回退

当前环境没有 Steamworks SDK，因此不会伪造在线功能。加载正式 Steam 插件后，成就和统计会优先发往平台，同时保留本地回退。

`tools/build_steam_store_pack.py` 会在发行构建时生成 `release/steam_store/`，其中包括商店图片、双语介绍、成就定义、云存档清单、标签和 `steam_app_build.vdf` 模板。真实 App ID、Depot ID 和 Valve 上传仍需要外部账号与正式 SDK。
