# MVP 0.1 验收清单

## 目标

跑通“起床 → 出门 → 打工 → 赚钱 → 买饭/吃饭 → 交租 → 睡觉”的单日生存闭环。

## 实现项

- [x] 全局时间系统：分钟 / 小时 / 日 / 星期，昼夜色调
- [x] 睡眠推进到次日早晨
- [x] 玩家基础移动与鼠标右键交互
- [x] 出租屋、街道、工厂、便利店占位场景
- [x] 工厂打卡与工资
- [x] 便利店固定物价购买
- [x] 极简自动堆叠背包与物品使用
- [x] 精力体感化，无数值面板
- [x] 月度房租自动扣除
- [x] 本地 JSON 存档 / 读档
- [ ] 3 个游戏日人工试玩
- [ ] 1 次完整 30 日房租周期自动测试
- [ ] 数值稳定性与刷钱漏洞巡查

## 明确未做

多城市区域、NPC AI、职业分支、天气、情绪、摸金收集、合成、联机、正式像素美术。
