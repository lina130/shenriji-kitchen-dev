# 《深日记》0.5.0 发行说明

## 本轮交付收尾

### 连续大城区与室内切换

- 主街已扩展为连续大城区地图，城中村、商业区、工业区、城郊自然区按物理位置分布，店铺、住宅、公共服务和自然景观不再全部堆在一条街上。
- 城门、店铺门、住宅门和区域道路改为实体入口；进入室内使用门切换，街道与室内保持不同尺度。
- Camera2D 以玩家为中心跟随，角色保持正常大小；地图缩放作用于镜头，而不是缩小整张场景根节点。
- 街道增加可接近的店面、道路、公共设施、自然景观和空间提示，减少无效空气墙、入口叠加和只能看不能玩的区域。

### 早餐店单手搬运点击流水线

- 顾客先排队、点单，玩家在菜单卡、工位、托盘和出餐台之间用鼠标单手搬运。
- 每道商品可以配置不同工序，半成品会进入托盘，必须手动送到下一工位。
- 早餐店与餐馆共用同一套点击流水线，经营反馈继续走场景交互而不是下拉菜单。

### 启动弹窗与 Esc 层级修复

- 修复进入游戏时先出现空弹窗、必须先按 Esc 才显示内容的问题。
- 修复 Esc 在模态界面、暂停界面和普通游戏界面之间的层级判断，关闭当前层后不会误开或残留上一层。
- 启动主菜单、继续游戏和进入场景时，UI 状态不会再抢占首帧输入。

### 事件解锁门控

- 节日、NPC 支线、限时摊主、特殊商品和限定收集物都按日期、关系、场景或进度门控触发。
- 未满足条件的系统不会提前暴露完整内容；已解锁事件会通过 NPC、场景或图鉴自然提示。
- 新游戏不会一次性注入全部长线内容，首周与后续阶段通过事件逐步展开。

### 首周经济闭环

- 摸金实际读取 data/balance.csv 的 daily_collection_points 和 collection_energy_cost。
- 当前配置为每日 6 点，每次成功发现消耗 2 点体力；可用次数受每日点数和剩余体力共同限制。
- 订单收益读取 data/business.csv 的 order_base_income 与 order_income_per_equipment_level，并保留配方售价、连击、天气、节日、时段和穿着加成。
- 已加入首周经济单项回归测试，验证摸金预算、每日刷新、存档恢复和订单收益公式，不把未复跑的全量测试写成通过结论。

### 测试选择器

- 新增 tools/test_map.json、tools/select_tests.py、tools/run_selected_tests.ps1 和 docs/TEST_SELECTION.md。
- 日常开发按 Git diff 和未跟踪文件选择相关门禁；编译检查永远先跑，失败即停。
- release 模式才选择完整门禁集合，正式发布仍以 build_release.ps1 的实际结果为准。

### 开发流程与多 Agent 持续编排

- 开发任务、角色输出和黑板状态位于 docs/ai_team，持续编排入口为 tools/run_ai_team_20m.ps1。
- 多 Agent 负责策划、世界、系统、存档、美术和 QA 分工，最终由主任务串行落盘、编译和验收，避免多个 Agent 同时改同一模块。
- 本节只说明开发流程，不替代构建产物或测试记录。

### 多工序流水线

- `data/recipes.csv` 为每道菜配置独立 `pipeline`。
- 备料、蒸、炸、煮、饮品和出餐分别绑定工位；半成品会进入托盘，必须手动送到下一工位。
- 设备升级只加快对应工位，例如升级油锅不会加快蒸笼。
- 早餐店排队点餐与餐馆流水线共用同一套生产规则。

### 早市、午市、晚市

- 早市 06:00–10:30，午市 10:30–15:00，晚市 17:00–23:00。
- 每个时段有独立菜单池、耐心、价格和需求倍率。
- 换市会清空未完成订单、半成品并切换设备；错过时段即失去该批客流。
- 一天约为现实 48 分钟，倍率位于 `data/balance.csv` 的 `real_seconds_per_game_minute`。

### 城中村夜市

- 新增独立夜市场景，18:00–23:00 开放，白天会由摊主提示尚未摆摊。
- 夜市可以补充鸡肉、面饼、河鲜等餐馆原料，也能购买夜宵、凉茶和参与抽签。
- 每晚最多购买三次，并可以帮摊主守一小时获得临时工钱。
- 节日夜里会额外出现限定小食摊。
- 小林、阿珍、强叔和小雨会在晚间出现在夜市，场景与 NPC 日程继续分离。

### 全年节日与限时 NPC

- 元旦、元宵、清明、劳动节、端午、儿童节、夏至、中秋、国庆、重阳、双十一、冬至、跨年夜全部拥有独立 NPC 事件。
- 节日当天会按地点出现限定摊主阿榕，并由他亲手交付当年限定纪念品。
- 新增 13 件节日限定旧物；它们只在对应节日进入摸金池，平日不会混入随机掉落。
- 节日场景会叠加灯笼、雨线、纸风车、月亮、购物霓虹、热汤蒸汽或跨年烟火等装饰层。
- 新增“节日里的人”和“一年四季”两条隐藏见闻，节日进度仍只通过 NPC 与图鉴自然呈现。

### 城中村招工与离职

- 员工拥有期望工资、诉求、士气、疲劳、欠薪、住宿、技能和来源渠道。
- 支持劳务市场、老乡介绍、熟人推荐和日结岗。
- 候选员工带独立姓名、来历、性格、能力暗示和专属立绘；劳务市场对话会由候选人本人说出诉求。
- 欠薪、低薪、长期加班、士气低落、春节返乡、工厂挖人、徒弟出师、隔壁店挖人和家人生病均可能触发离职。
- 可通过加薪、年终奖、包住、调休、教手艺和垫路费留人。

### 自动存档

- 手动档与自动档分开保存，各自采用临时文件原子替换并保留 3 份轮转备份。
- 定时存档按游戏内绝对时间差判断，每约 15 游戏分钟触发一次；读旧档导致时间回退后仍能继续触发。
- 换市、开关档、睡觉、进货、买卖、雇人离职、种收、宠物行动、买家具等关键节点立即保存。
- 新写入存档带 SHA-256 校验和；旧档没有校验和时仍兼容读取，下一次保存会补齐。
- 读取顺序为手动主档、手动备份、自动主档、自动备份；主档损坏时自动回退到最近有效备份。
- 读档失败会锁定覆盖保护，不会用损坏档覆盖原档；玩家确认放弃原档或开始新游戏后才恢复写入。
- 当前 SAVE_VERSION=15，支持 v1 至 v15 的逐级迁移；未来版本或缺少版本号的存档会被拒绝加载。
- 读档失败、迁移失败和未来版本拒绝都会保留原档，便于人工恢复。
### 职业、服装与地图

- 角色不再开局自带工作。现有餐饮、工厂、写字楼、学业、体制、自由职业、物流仓配和手艺技工八条路线，都能通过负责人暗示晋升，不显示进度条。
- 班次表现会受体力、健康、压力和工作服影响；连续低绩效先由负责人私下提醒，再触发裁员。被裁后获得结算补偿，可重新应聘其他路线。
- 工业区新增物流港仓和手艺工坊两个独立工作场景，可以正式上班，也可以装卸、调度、维修和练习手艺。
- 城中村营业时有随机客流和实时手速操作；自己没有亲自经营时，只有雇到员工才会产生很慢的被动收入。
- 商业区新增服装店；服装会改变角色外观，并带来社交或工作手感。
- 地图拆为城中村、商业区、工业区、城郊四个生活圈，银行、餐馆、工厂、农场等不再全部堆在一条街。
- 城市地图改为相机跟随时，玩家保持正常大小；镜头可在合理范围内缩放，不再缩放整张场景根节点。
- 门、店铺入口和区域道路改为走入触发，经营物件保留鼠标点击，传送门式点击逐步退出。
- 商业区和工业区使用 scene_zones.csv 分区校验，店面、公共服务、工厂、仓配和自然区各有边界，场景检查会阻止越区和单区过密。
- 背包扩容改在服装店缝纫机前现场完成，房产买卖改由商业区方姐和房屋模型承接，不再靠背包菜单一键购买。
- 新增方姐、阿珂、余老师三位常驻 NPC，候选员工也有独立立绘和人物小传。
- 节日解锁元宵汤圆、端午粽子、中秋月饼和冬至饺子等限定商品。

### 剧情、农场与交互修正

- 新游戏通过 NPC 对话展开章节式生活剧情，并在每日生活中触发邻里、天气、加班和交易等偶发事件。
- 偶发事件扩展到 34 条，覆盖农场生长、压力、健康、孩子情绪、宠物心情、夜校、港仓、维修、摄影和职业生活。
- 农场加入可升级锄头、洒水壶、堆肥桶、自动喷灌；雨天自动浇灌、酷暑缺水减速，天气会联动作物收购价。
- 新增独立农场圈舍场景，可购买鸡舍、奶牛棚和猪圈，喂饲料后按天收蛋、牛奶和猪肉。
- 饲料进入批发库存，家畜产物直接进入餐馆仓库；养殖与种植在同一套农场经济闭环中运作。
- 所有经营核心操作改为场景点击：菜单卡、工位、托盘、设备升级、农场作物/工具/地块都不再依赖列表式 HUD。
- 所有短提示改为 NPC 对话气泡，并在场景中轮换显示 NPC 暗示。
- 修复进游戏先出现空弹窗、必须按 Esc 才消失的问题。
- 清理餐馆、旧货市场、农场、批发等场景的空气墙和错误出口位置；逐场景检查全部出口。
- 宠物入口只在收养后出现在出租屋生活区，未收养时不会提前暴露宠物窝。
- 早餐店拆为前厅和后厨：前厅只负责排队、点餐和取餐，后厨独立放置菜单、工位、托盘和设备升级。
- 新增河边自然保护区，可散步、休息、拍照和发现偶发旧物；强叔、小雨等 NPC 会按周末、节日和时段限时出现。
- 城市主街扩为 2560×1440 多分区大地图，城中村、商业区、工业区、城郊自然区按物理位置分布，不再把入口堆成一排按钮。
- 出租屋拆成卧室和生活区：卧室只保留床、书桌、装修与卧室门；冰箱、木箱、收购箱、收音机、宠物和住房升级移到生活区。
- 场景切换统一使用实体门/入口，地图面板显示城市俯瞰图、所属分区和“你在这里”标记。
- 玩家选中的快捷栏物品会绘制到角色手边；经营与大地图入口增加门框或路线指示。
- NPC 扩充性格、用途和专属提示；黄姐、阿珍、强叔、小雨分别服务早餐、服装、自然区域和周末彩蛋。
- 所有物品在背包中显示明确用途；食物饮料可食用，种子、宠物用品、装饰物和节日纪念品均接入实际系统。
- 像素角色生成已改为读取 `data/npcs.csv`，新增 NPC 会自动获得世界图与肖像资源。

### 百件城市收藏

- 城中收藏物从 37 件扩展到 100 件，覆盖旧金属、瓷器玻璃、旧书纸品、相机影像和市井杂货五类行情。
- 新增 63 件旧物都带独立名称、来路描述、稀有度、出售价格、送礼 NPC 和展示属性。
- 新增“百件城中旧物”隐藏见闻，鼓励长期探索但不加入任务列表。

### NPC 个人支线

- 梅姨、王师傅、小林、陈伯、黄姐、阿珍、强叔、小雨各自拥有三段个人故事。
- 支线由关系、职业、住房、家庭、收藏、旅行、兴趣、宠物和经营条件自然触发。
- 对话内容继续遵守人物性格，不出现任务列表、进度条或系统口吻的人物台词。
- 支线会奖励真实可用的食物、饮品、家具或金钱，并记录在人物关系与图鉴摘要中。
- 新增“听了一段旧事”和“城里人的故事”两条隐藏见闻。

### 像素美术与生活扩展

- 新增可复现像素美术生成管线，输出场景背景、NPC 肖像、物品图标和 UI 纹理。
- 角色动画扩展为四帧行走、四帧工作和吃饭、睡觉、交互、拾取动作帧；NPC 会按当天活动自动切换动作。
- 场景、人物、物品、UI、字体统一通过 `PresentationManager` 和资源绑定表接入，方便正式美术替换。
- 新增河边钓鱼：下竿/收线、鱼竿升级、天气与时段鱼种、鱼获进入餐馆仓库。
- 住房升级扩展为城中村单间、独立小单间、一室一厅、河边公寓、云城高层公寓和云端花园住宅。
- 新增高端住宅区场景，包含置业处、楼顶花园、街角咖啡店和社区画廊，住房会继续影响房租、睡眠、学习和放松。
- 职业扩展为餐饮、工厂、写字楼、学业、体制、自由职业六条主线。

### 隐藏见闻与长期内容

- 新增隐藏见闻系统，不显示任务列表，只通过 NPC 线索和玩家行为自然解锁。
- 覆盖第一份工钱、多工序出餐、钓鱼、旅游、招聘、农场、宠物、创业、住房和六条职业路线。

### 合作与发行接口

- 新增 2–4 人纯合作会话接口：主机、加入、离房、人数限制和连接事件。
- F6 打开好友与平台界面，可创建或加入真实 ENet 房间，并查看平台状态与房间成员。
- 已经同步好友的场景、位置和朝向，远程玩家会在同一场景中显示。
- 房主会同步共同资金、库存、店铺、农场、员工、生意、房间和夜市状态；访客自动接收快照，涉及共同账本的交易会提交给房主执行。
- 访客可以提交批发买卖、店铺升级、农场种植/养殖、夜市交易和厨房操作请求，房主执行后再广播最新账本。
- 厨房班次、订单、工位、半成品托盘、设备和营业状态会进入共同快照，访客能实时看到房主处理后的厨房进度。
- 新增 Steam/平台接口层：成就、统计、云存档能力检测和本地回退。
- 未加载 Steamworks SDK 时不伪造平台能力，单机内容不受影响。
- 新增 Steam 商店素材生成工具，输出头图、胶囊图、截图、双语商店介绍、成就清单、云存档清单和上传配置模板。
- 新增本地模组数据接口，可从 user://mods 合并 CSV 配置，为后续创意工坊接入做准备。

### 恋爱、婚姻与家庭

- 基于现有 NPC 关系值增加确认关系、求婚和成家路线。
- 成家需要稳定住房；家庭状态会改善睡眠恢复和居家生活。
- 有孩子后，家中会多出真实照看入口。孩子会按游戏天数从新生儿成长到学步、上学、懂事和半大孩子，陪伴、喂养、教学和出游会改变亲近感与情绪。
- 家庭状态与 NPC 对话、住房、存档和隐藏见闻联动。

### 隐藏情绪、压力与通勤

- 新增隐藏情绪、压力和天气体感状态，不使用属性条显示。
- 通勤可能触发堵车、路边风景或小运气事件。
- 疲劳、压力和好心情会影响工资、社交和行动效率。
- 状态通过 NPC 暗示和行动结果自然感知。

### 渐进解锁

- 新增戴夫式生活层级解锁：职业、剧情、生意和天数会逐步开放城郊、河边、长途旅行和山林温泉。
- 未开放路线通过巴士司机、绿道管理员等 NPC 暗示，不使用任务列表。

### 医疗与健康

- 新增社区诊所及体检、感冒处理、心理咨询、推拿理疗和牙科服务。
- 健康过低时不能继续硬撑工作，会通过诊所护士提示。
- 就医会消耗金钱和时间，并可能恢复体力、降低压力。

### 学业与证书

- 新增城市夜校/大学校区，可报名办公、销售、编程、公考、摄影和设计课程。
- 上完课并通过阶段练习后获得证书，证书会提高对应职业的收入。
- 课程和证书记录接入存档与图鉴，不使用任务进度条。
- 课程学完后进入隐藏结业考核；通过后发证，证书会解锁办公、体制、自由职业部分中高级岗位。

### 场景环境音

- 街道、商业区、工业区、农场、河边、餐馆、早餐店、夜市、诊所、大学和旅行地点分别绑定独立环境音。
- 天气、昼夜和节日会参与环境音切换；雨天的室外场景优先使用雨声，节日场景优先使用节日音轨。

### 首批正式场景覆盖

### 更多城市 NPC

- 市场管理员、公交司机可进入熟人推荐渠道，城市不再只靠少数核心人物提供提示。

### 窗口与设置

- 设置界面新增 1280×720、1600×900、1920×1080 三档窗口分辨率，窗口模式支持全屏切换。

- 默认仍使用 1600×900 窗口，兼顾桌面阅读和多场景布局。

- 每位 NPC 增加开心、疲惫、担忧三套表情头像，原有头像作为平静状态保留。

### UI 纹理覆盖

- 面板、行动按钮和背包格接入统一 UI 纹理，按钮保存正常、悬停、按下三种视觉反馈。

- 背包格文本、数量、空位提示和拖动反馈继续保留，不影响现有星露谷式操作。

- 场景背景加入天空渐变、地面材质、建筑轮廓、灯光、树木、水面、室内桌椅和前景阴影，街道、室内、自然区域不再共用同一种平面构图。

- `PresentationManager` 新增正式资源覆盖路径：把同名 PNG 放到 `assets/art/formal/` 即可覆盖程序化基线，不需要修改业务脚本。
- 当前仍是可玩的 Beta 程序化美术基线，正式商业美术、逐帧动画和音频替换继续留在总案阶段 5。
- 场景和角色资源可以独立替换，UI、字体和物品绑定继续通过稳定 key 查询。

### 六类城市图鉴

- F1 图鉴改为物品、美食、场景、职业、纪念品和旧物六类标签，每类都有自己的发现状态和说明。
- 拿到物品、做起菜品、走过场景、接触职业时会自然留下记录；未发现内容只显示空页，不生成任务清单。
- 节日纪念品单独归档，和普通旧物分开；每个条目继续显示稀有度、已有状态和实际用途。

- 新增多条人生阶段结局记录，达到条件后不会强制结束游戏。

- 覆盖稳定生活、四类生意、第一桶金、主厨、车间主管、学业证书、旅行收藏、旧物全收集和家庭宠物等人生状态。

### 兴趣与治愈独处

- 新增社区活动中心与摄影、音乐、绘画、健身、园艺、夜读课程。
- 兴趣练习会消耗时间和体力，同时恢复情绪、降低压力。
- 兴趣等级会提高相关自由职业收入，音乐和绘画也会改善社交手感。

### 节日比赛与聚会

- 节日活动不再只发放同一套奖励。比赛会根据体力、健康、情绪和压力计算隐藏表现，并结算名次奖励。
- 聚会会恢复情绪、降低压力，并留下更温和的社交反馈；节日纪念品、限定菜单和年度收集保持不变。
- 不同节日继续使用各自场景、摊主、装饰和纪念旧物，比赛与聚会共享节日入口但结算逻辑不同。

### NPC 多时段对话池

- 9 位常驻 NPC 的早、中、晚对话扩展到 81 条，避免每个时段反复说同一句。
- 对话支持天气、职业路线和最低好感条件筛选；雨天、雾天、上班中或关系走近后会出现不同台词。
- 人物台词继续保留性格和用途差异，系统、场景、NPC 三类提示来源不混用。

### 多业态现场经营

- 街边地摊、小吃饮品店、零售百货店和小型加工厂不再只是被动分红。
- 每个业态有独立的运营时长、体力消耗、劳力/脑力消耗和备货要求。
- 现场照看会即时消耗库存并结算收入，收入会受店面等级、员工能力、口碑和天气影响。
- 不亲自经营时仍保留较慢的每日分成；主动经营与被动经营形成两条收益路径。
