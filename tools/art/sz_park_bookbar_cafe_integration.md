# SZ-PARK-BOOKBAR-01 · 人才公园咖啡书吧接入

状态：首版正式模型；已完成 Blender 导出与两视角预览检查，仍需在 Godot 实机检查碰撞、遮挡和夜景。

- 整体预览：`assets/art/models/sz_park_bookbar_cafe_preview.png`

- 设计依据：[深圳市南山区政府介绍深圳人才公园](https://www.szns.gov.cn/mlns/stns/lc/csgy/content/post_12595660.html)提到园内人才书吧提供阅读、观景、休憩及咖啡、饮品、糕点售卖。本资产是原创的开放式园区餐饮书吧，不照搬真实建筑外形。

## 比例与放置

- Blender 尺寸单位米，`+Z` 朝上，`-Y` 为面对公园的开放服务面；导入 Godot 后，上轴为 `+Y`，开放面为 `+Z`。
- 基座约 **9.6 米宽 × 7.5 米深**，底面中心为模型原点。甲板上表面本地 `Godot y≈0.20`。叶形后屋顶最高约 `Godot y≈4.25`。
- 若地图将园区书吧中心设为 `REST_ANCHOR=Vector3(-310,0,120)`，建议模型原点置于 `Vector3(-310,-0.20,120)`，让基座上表面与地面 y=0 对齐。世界位置中本地 `+Z` 指公园开放广场。
- 建议玩家进入/出生点为模型本地 `(0,0.20,+4.6)`，对应上述放置的世界约 `(-310,0,124.6)`。公园步道在建筑前至少留 2 米。
- 屋顶前半部采用透空木格栅，正常俯视镜头可看到台面；若镜头从后方压低，可对整个屋顶设置渐隐，不要给玩家显示浮空建筑文字。

## Godot 简化碰撞建议

不要对数百个杯碟、书本和食物启用网格碰撞。建议在餐馆实例下用 7–9 个简单 `BoxShape3D`：

1. **地板**：中心 `(0,0.10,0)`，尺寸 `(9.6,0.20,7.5)`；若外部地图已有完整地板且高度一致，可省略。
2. **后墙与侧墙**：后墙中心 `(0,1.73,-2.86)`，尺寸 `(8.15,3.04,0.25)`；侧墙用 x≈±3.99、z≈-1.46 的两条窄盒，厚约 0.15 米。
3. **备料/加热岛**：中心 `(-2.42,0.63,-0.30)`、`(-0.35,0.63,-0.30)`，尺寸分别约 `(2.22,1.0,0.92)` 与 `(1.90,1.0,0.92)`。
4. **出餐/付款柜台**：中心 `(+0.80,0.65,+1.32)` 与 `(+2.81,0.67,+1.72)`，尺寸约 `(1.75,1.02,0.70)` 与 `(1.78,1.06,0.86)`。
5. **侧边花箱**：x≈±4.25、z≈+0.20，尺寸 `(0.64,0.44,5.87)`；后续可统一归入公园地形碰撞。

玻璃、格栅、灯和植物优先保持视觉模型，不阻挡交互射线。餐台交互射线应落在锚点附近的触发 Area；玩家实际站位在地板上，避免被台面锚点的 y 值抬离地面。动态消费与收集数据应由玩法系统保存，GLB 只负责可见几何与稳定的节点位置。
